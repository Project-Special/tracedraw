# Fonts in the browser build's font folder (site/fonts). The page fetches a
# family's files the first time a drawing's text needs it: text set in the
# family, in a family it stands in for (see `substitutes` in
# crates/text/src/lib.rs), or letters of a script only it has. Built by
# web/font_folder.py; see FONTS.md for the licences.
#
# Each line: family | source | files
#   gf          paths in the google/fonts repository at the commit below;
#               the folder's licence file comes along
#   deb:<pkg>   file names searched under /usr/share/fonts and
#               /usr/share/texmf once the package is installed; its
#               copyright file comes along
# "licence | deb:<pkg>" copies a package's copyright file only (the fonts
# build.rs bundles into the module).
