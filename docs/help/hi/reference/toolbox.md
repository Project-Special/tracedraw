# टूलबॉक्स

टूलबॉक्स में ड्रॉइंग और संपादन के सभी टूल समूहों में होते हैं। छोटे तीर वाला बटन
एक फ़्लायआउट खोलता है जिसमें उसके समूह के बाकी टूल होते हैं। यह पेज हर टूल को
उसके शॉर्टकट और उसे समझाने वाले पेज के साथ सूचीबद्ध करता है। टूल की कुंजियाँ
बदलने के लिए देखें [अनुकूलन विकल्प](../customize/customization.md#commands)।
