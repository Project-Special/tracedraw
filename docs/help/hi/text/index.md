# टेक्स्ट

TraceDraw में दो तरह का टेक्स्ट होता है। **कलात्मक टेक्स्ट** किसी बिंदु पर रखी
एक या कुछ पंक्तियाँ होती हैं: शीर्षक, लेबल, लोगो। **अनुच्छेद टेक्स्ट** एक फ़्रेम
के अंदर बहता है और उसके किनारों पर लपेटता है: मुख्य पाठ, कॉलम, सूचियाँ। दोनों
को अक्षर दर अक्षर फ़ॉर्मेट किया जा सकता है, पथ पर बैठाया जा सकता है और वर्तनी
जाँची जा सकती है।

ये पेज टेक्स्ट जोड़ना और फ़ॉर्मेट करना, अनुच्छेदों का लेआउट, फ़ॉन्ट और विशेष
वर्ण चुनना, और लेखन टूल का उपयोग समझाते हैं।
