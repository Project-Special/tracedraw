# फ़ाइल फ़ॉर्मेट

TraceDraw अपने फ़ॉर्मेट `.tdraw` में सहेजता है, जो सब कुछ रखता है, और `.cdr`
फ़ाइलें भी सहेजता है। यह कई दूसरे फ़ॉर्मेट खोलता और इंपोर्ट करता है, और वेक्टर,
बिटमैप और प्रिंट फ़ॉर्मेट में एक्सपोर्ट करता है। ये पेज फ़ॉर्मेट की सूची देते हैं
और इंपोर्ट, एक्सपोर्ट और PDF प्रकाशित करना समझाते हैं।
