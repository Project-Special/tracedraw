# प्रिंटिंग

TraceDraw शीटों का प्रिंट के लिए तैयार PDF बनाकर प्रिंट करता है, जिसे आपके
सिस्टम का व्यूअर प्रिंटर को भेजता है। ये पेज प्रिंट डायलॉग बॉक्स और उसका
पूर्वावलोकन, कई संस्करण प्रिंट करने के लिए डिज़ाइन में डेटा मर्ज करना, प्रिंट से
पहले ड्रॉइंग जाँचना, और बैनर को बॉर्डर और ग्रोमेट से पूरा करना समझाते हैं।
