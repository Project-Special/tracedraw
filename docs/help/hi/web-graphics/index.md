# वेब ग्राफ़िक्स

वेब पेज, ऐप और स्क्रीन के ग्राफ़िक्स आमतौर पर स्क्रीन रिज़ॉल्यूशन वाले बिटमैप
(PNG, JPEG, WebP, GIF) होते हैं, या SVG फ़ाइलें जो किसी भी आकार में साफ़ रहती हैं।
ये पेज समझाते हैं कि उन्हें एक-एक करके कैसे एक्सपोर्ट करें और कई पेज और ऑब्जेक्ट
एक साथ कैसे एक्सपोर्ट करें।

ऑब्जेक्ट ऐसे लिंक भी रख सकते हैं जो एक्सपोर्ट की गई SVG, HTML और PDF फ़ाइलों में
काम करते हैं; देखें [लिंक और बुकमार्क](../objects/links.md)।
