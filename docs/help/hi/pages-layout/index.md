# पेज और लेआउट

एक ड्रॉइंग में कई पेज हो सकते हैं, हर एक का अपना आकार और अभिविन्यास। ये पेज
समझाते हैं कि पेज कैसे जोड़ें, व्यवस्थित करें और क्रमांकित करें, दस्तावेज़ के
विकल्प (पेज आकार, लेआउट, पृष्ठभूमि, ब्लीड, रूलर, ग्रिड और गाइडलाइन) कैसे सेट
करें, गाइडलाइन कैसे लगाएँ, ऑब्जेक्ट को जगह पर कैसे स्नैप करें और ड्रॉइंग के गुण
कैसे पढ़ें।
