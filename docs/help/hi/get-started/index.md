# शुरुआत करें

ये पेज TraceDraw का परिचय देते हैं: विंडो के हिस्से, ड्रॉइंग बनाना, खोलना और
सहेजना, ड्रॉइंग में घूमना और काम पूर्ववत करना, और ड्रॉइंग करते समय मदद कहाँ
मिलती है।

TraceDraw Windows, macOS और Linux पर, और बिना कुछ इंस्टॉल किए वेब ब्राउज़र में
चलता है। दोनों एक ही प्रोग्राम हैं; ब्राउज़र संस्करण के कुछ अंतर
[ब्राउज़र संस्करण](browser-version.md) में समझाए गए हैं।
