# रंग, फ़िल और पारदर्शिता

हर ऑब्जेक्ट के अंदर फ़िल और किनारे पर आउटलाइन हो सकती है। ये पेज समझाते हैं कि
पैलेट और [[docker.color]] पैनल से रंग कैसे चुनें, फ़िल के प्रकार (एकसमान रंग,
ग्रेडिएंट, पैटर्न, टेक्सचर या मेश), ऑब्जेक्ट को पारदर्शी कैसे बनाएँ, और रंग
स्टाइल, स्पॉट स्याही और रंग प्रबंधन से रंगों को एकरूप कैसे रखें।
