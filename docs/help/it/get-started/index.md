# Per iniziare

Queste pagine presentano TraceDraw: le parti della finestra, come creare,
aprire e salvare disegni, come muoversi in un disegno e annullare il lavoro, e
dove trovare aiuto mentre disegnate.

TraceDraw funziona su Windows, macOS e Linux, e in un browser web senza
installare nulla. Si tratta dello stesso programma; le poche differenze della
versione per browser sono spiegate in
[La versione per browser](browser-version.md).
