# Pagine e layout

Un disegno può avere molte pagine, ognuna con le sue dimensioni e il suo
orientamento. Queste pagine spiegano come aggiungere, ordinare e numerare le
pagine, impostare le opzioni del documento (formato, layout, sfondo, abbondanza,
righelli, griglia e linee guida), posizionare linee guida, agganciare gli
oggetti e leggere le proprietà di un disegno.
