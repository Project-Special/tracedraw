# Grafica per il web

La grafica per pagine web, app e schermi è di solito fatta di bitmap (PNG,
JPEG, WebP, GIF) a risoluzione dello schermo, o di file SVG che restano nitidi
a qualsiasi dimensione. Queste pagine spiegano come esportarli uno alla volta e
come esportare molte pagine e oggetti in una volta.

Gli oggetti possono anche avere collegamenti che funzionano nei file SVG, HTML
e PDF esportati; vedere [Collegamenti e segnalibri](../objects/links.md).
