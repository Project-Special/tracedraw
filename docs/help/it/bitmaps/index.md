# Bitmap

Le bitmap sono immagini fatte di pixel, come foto e scansioni. TraceDraw le
colloca nei disegni, ne cambia la modalità colore e le dimensioni, le
raddrizza, maschera colori, applica effetti e le vettorizza in forme. Converte
anche oggetti vettoriali in bitmap.

Per inserire un'immagine usate [[menu.file > menu.file.import]]; vedere
[Importare file](../file-formats/import.md). Con una bitmap selezionata, la
barra delle proprietà contiene i comandi bitmap: modifica, ritaglio,
vettorizzazione, raddrizzamento e ricampionamento. Per gli effetti, vedere
[Effetti bitmap](../effects/bitmap-effects.md).
