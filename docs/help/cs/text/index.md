# Text

TraceDraw má dva druhy textu. **Umělecký text** je řádek nebo několik řádků
umístěných v bodě: nadpisy, popisky, loga. **Odstavcový text** teče v rámečku a
zalamuje se na jeho okrajích: souvislý text, sloupce, seznamy. Oba lze
formátovat znak po znaku, přizpůsobit cestám a kontrolovat jejich pravopis.

Tyto stránky vysvětlují přidávání a formátování textu, sazbu odstavců, výběr
písem a speciálních znaků a používání nástrojů pro psaní.
