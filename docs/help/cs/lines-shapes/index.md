# Čáry, tvary a obrysy

Vše, co v TraceDraw nakreslíte, se skládá z čar a tvarů. Tyto stránky
vysvětlují nástroje, které je kreslí, jak je upravovat uzel po uzlu, jak je
kombinovat a řezat a jak nastavit obrys, který kreslí jejich okraje.

Čáry a křivky se kreslí nástroji rozbalovací nabídky Křivka, obdélníky,
elipsy, mnohoúhelníky a další tvary vlastními nástroji. Každý objekt lze po
nakreslení upravit nástrojem [[tool.shape]].
