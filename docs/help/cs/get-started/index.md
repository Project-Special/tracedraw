# Začínáme

Tyto stránky představují TraceDraw: části okna, vytváření, otevírání a ukládání
kreseb, pohyb po kresbě a vracení změn a kde při kreslení najdete pomoc.

TraceDraw běží ve Windows, macOS a Linuxu a ve webovém prohlížeči bez
instalace. Jde o stejný program; těch pár rozdílů verze pro prohlížeč
vysvětluje [Verze pro prohlížeč](browser-version.md).
