# Webová grafika

Grafika pro webové stránky, aplikace a obrazovky jsou obvykle bitmapy (PNG,
JPEG, WebP, GIF) v rozlišení obrazovky nebo soubory SVG, které zůstávají ostré
v jakékoli velikosti. Tyto stránky vysvětlují, jak je exportovat jednotlivě a
jak exportovat mnoho stránek a objektů najednou.

Objekty mohou nést i odkazy, které fungují v exportovaných souborech SVG, HTML
a PDF; viz [Odkazy a záložky](../objects/links.md).
