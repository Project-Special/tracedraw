# Objekty, symboly a vrstvy

Každý tvar, čára, text a obrázek v kresbě je objekt. Tyto stránky vysvětlují,
jak objekty vybírat, přesouvat, měnit jejich velikost, otáčet je a zarovnávat,
jak je řadit, seskupovat a uspořádat do vrstev a jak je znovu používat jako
symboly.

Věnují se i objektům s vlastním úkolem: tabulkám, čárovým a QR kódům,
komentářům a datům připojeným k objektům.
