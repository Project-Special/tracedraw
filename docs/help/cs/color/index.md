# Barvy, výplně a průhlednosti

Každý objekt může mít uvnitř výplň a podél okraje obrys. Tyto stránky
vysvětlují, jak vybírat barvy z palet a panelu [[docker.color]], druhy výplní
(jednolitá barva, přechod, vzorek, textura nebo síť), jak objekty zprůhlednit a
jak udržet barvy jednotné pomocí barevných stylů, přímých barev a správy barev.
