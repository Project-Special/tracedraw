# Bitmapy

Bitmapy jsou obrázky složené z pixelů, například fotografie a skeny. TraceDraw
je umisťuje do kreseb, mění jejich barevný režim a velikost, narovnává je,
maskuje barvy, používá efekty a vektorizuje je na tvary. Umí také převést
vektorové objekty na bitmapy.

Obrázek vložíte příkazem [[menu.file > menu.file.import]]; viz
[Import souborů](../file-formats/import.md). Když je vybrána bitmapa, panel
vlastností obsahuje příkazy pro bitmapy: úpravy, oříznutí, vektorizaci,
narovnání a převzorkování. Efekty viz
[Bitmapové efekty](../effects/bitmap-effects.md).
