# Šablony a styly

Šablony a styly šetří práci, kterou byste jinak opakovali. **Šablona** je
hotová kresba, od které začnete. **Styl** je pojmenovaná sada výplně, obrysu a
průhlednosti, která zůstává propojená s objekty, které ji používají, takže
jedna změna upraví všechny. **Výchozí vlastnosti** určují vzhled nových
objektů.

Barevné styly, které fungují stejně pro jednotlivé barvy, vysvětluje stránka
[Barevné styly](../color/color-styles.md).
