# Tisk

TraceDraw tiskne tak, že vytvoří PDF archů připravené k tisku, které prohlížeč
vašeho systému pošle na tiskárnu. Tyto stránky vysvětlují dialogové okno Tisk a
jeho náhled, jak sloučit data s návrhem a vytisknout mnoho verzí, jak kresbu
před tiskem zkontrolovat a jak dokončit bannery okrajem a průchodkami.
