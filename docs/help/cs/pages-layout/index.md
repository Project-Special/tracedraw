# Stránky a rozvržení

Kresba může mít mnoho stránek, každou s vlastní velikostí a orientací. Tyto
stránky vysvětlují, jak stránky přidávat, řadit a číslovat, nastavit volby
dokumentu (velikost stránky, rozvržení, pozadí, spadávka, pravítka, mřížka a
vodítka), umisťovat vodítka, přichytávat objekty a číst vlastnosti kresby.
