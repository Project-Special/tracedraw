# Speciální efekty

Efekty mění vzhled objektu, aniž by měnily objekt samotný: prolnutí vyplní
prostor mezi dvěma objekty, kontura nakreslí kolem objektu prstence, obálka ho
ohne, vysunutí mu dá objem, stín ho oddělí od stránky. Většina efektů je
**živá**: objekt si ponechá svůj tvar a efekt se z něj kreslí, takže efekt
můžete kdykoli změnit nebo odstranit.

Efekty najdete v nabídce [[menu.effects]], v rozbalovací nabídce Efekty panelu
nástrojů a ve vlastních panelech. [Bitmapové efekty](bitmap-effects.md) mění
pixely obrázků nebo objektů kreslených jako obrázky.
