# Web grafikleri

Web sayfaları, uygulamalar ve ekranlar için grafikler genellikle ekran
çözünürlüğünde bitmapler (PNG, JPEG, WebP, GIF) ya da her boyutta keskin kalan
SVG dosyalarıdır. Bu sayfalar onları tek tek dışa aktarmayı ve birçok sayfa ve
nesneyi aynı anda dışa aktarmayı açıklar.

Nesneler dışa aktarılan SVG, HTML ve PDF dosyalarında çalışan bağlantılar da
taşıyabilir; bkz. [Bağlantılar ve yer imleri](../objects/links.md).
