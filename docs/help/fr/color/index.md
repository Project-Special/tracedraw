# Couleurs, remplissages et transparences

Chaque objet peut avoir un remplissage à l'intérieur et un contour le long de
son bord. Ces pages expliquent comment choisir des couleurs dans les palettes
et le panneau [[docker.color]], les types de remplissage (une couleur unie, un
dégradé, un motif, une texture ou un maillage), comment rendre des objets
transparents et comment garder des couleurs cohérentes avec les styles de
couleur, les tons directs et la gestion des couleurs.
