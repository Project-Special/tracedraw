# Bitmaps

Les bitmaps sont des images faites de pixels, comme les photos et les
numérisations. TraceDraw les place dans les dessins, change leur mode de
couleur et leur taille, les redresse, masque des couleurs, applique des effets
et les vectorise en formes. Il transforme aussi des objets vectoriels en
bitmaps.

Pour faire entrer une image, utilisez [[menu.file > menu.file.import]] ; voir
[Importer des fichiers](../file-formats/import.md). Quand un bitmap est
sélectionné, la barre de propriétés contient les commandes bitmap : modifier,
recadrer, vectoriser, redresser et rééchantillonner. Pour les effets, voir
[Effets bitmap](../effects/bitmap-effects.md).
