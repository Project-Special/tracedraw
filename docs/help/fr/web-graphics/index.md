# Graphismes web

Les graphismes pour les pages web, les applications et les écrans sont
généralement des bitmaps (PNG, JPEG, WebP, GIF) à la résolution de l'écran, ou
des fichiers SVG qui restent nets à toutes les tailles. Ces pages expliquent
comment les exporter un par un et comment exporter de nombreuses pages et
objets à la fois.

Les objets peuvent aussi porter des liens qui fonctionnent dans les fichiers
SVG, HTML et PDF exportés ; voir [Liens et signets](../objects/links.md).
