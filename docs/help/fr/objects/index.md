# Objets, symboles et calques

Chaque forme, ligne, texte et image d'un dessin est un objet. Ces pages
expliquent comment sélectionner des objets, les déplacer, les redimensionner,
les faire pivoter et les aligner, comment les ordonner, les grouper et les
organiser en calques, et comment les réutiliser sous forme de symboles.

Elles traitent aussi des objets qui ont un rôle propre : tableaux, codes-barres
et codes QR, commentaires et données associées aux objets.
