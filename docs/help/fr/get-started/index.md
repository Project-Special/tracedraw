# Prise en main

Ces pages présentent TraceDraw : les parties de la fenêtre, comment créer,
ouvrir et enregistrer des dessins, comment se déplacer dans un dessin et
annuler son travail, et où trouver de l'aide pendant le dessin.

TraceDraw fonctionne sous Windows, macOS et Linux, et dans un navigateur web
sans rien installer. C'est le même programme ; les quelques différences de la
version pour navigateur sont expliquées dans
[La version pour navigateur](browser-version.md).
