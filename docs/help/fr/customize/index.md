# Personnaliser et automatiser

TraceDraw peut être réglé selon votre façon de travailler : options du
programme et de chaque outil, apparence de l'interface, raccourcis clavier,
barres et espaces de travail. Vous pouvez aussi automatiser le travail avec des
scripts, connecter un service d'IA pour dessiner d'après une description et
suivre le temps passé sur un dessin.

Les options se trouvent dans [[menu.tools > menu.tools.options]] : chaque
élément ouvre sa propre boîte de dialogue. Les changements apparaissent tout de
suite ; [[dialog.ok]] les garde et [[dialog.cancel]] remet tout comme avant. Le
bouton **?** ouvre la page de cette Aide consacrée à la page d'options
affichée.
