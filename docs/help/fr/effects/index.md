# Effets spéciaux

Les effets changent l'apparence d'un objet sans changer l'objet lui-même : un
dégradé de formes remplit l'espace entre deux objets, une silhouette dessine
des anneaux autour d'un objet, une enveloppe le courbe, une extrusion lui donne
du volume, une ombre le détache de la page. La plupart des effets sont
**dynamiques** : l'objet garde sa propre forme et l'effet est dessiné à partir
de lui, vous pouvez donc modifier ou supprimer l'effet à tout moment.

Les effets se trouvent dans le menu [[menu.effects]], dans le menu volant
Effets de la boîte à outils et dans leurs propres panneaux. Les
[effets bitmap](bitmap-effects.md) changent les pixels des images, ou des
objets dessinés comme des images.
