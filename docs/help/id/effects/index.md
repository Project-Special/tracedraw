# Efek khusus

Efek mengubah tampilan objek tanpa mengubah objeknya: paduan mengisi ruang
antara dua objek, kontur menggambar cincin di sekeliling objek, amplop
membengkokkannya, ekstrusi membuatnya tampak padat, bayangan memisahkannya dari
halaman. Sebagian besar efek bersifat **hidup**: objek mempertahankan
bentuknya sendiri dan efek digambar darinya, sehingga Anda dapat mengubah atau
menghapus efek kapan saja.

Efek ada di menu [[menu.effects]], di menu lipat Efek pada kotak alat, dan di
panelnya sendiri. [Efek bitmap](bitmap-effects.md) mengubah piksel gambar,
atau piksel objek yang digambar sebagai gambar.
