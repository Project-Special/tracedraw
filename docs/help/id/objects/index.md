# Objek, simbol, dan lapisan

Setiap bentuk, garis, teks, dan gambar dalam sebuah gambar adalah objek.
Halaman-halaman ini menjelaskan cara memilih objek, memindahkan, mengubah
ukuran, memutar, dan meratakannya, cara mengurutkan, mengelompokkan, dan
menatanya dalam lapisan, serta cara memakainya ulang sebagai simbol.

Halaman ini juga membahas objek dengan tugas khusus: tabel, kode batang dan
kode QR, komentar, dan data yang dilampirkan ke objek.
