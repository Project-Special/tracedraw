# Grafis web

Grafis untuk halaman web, aplikasi, dan layar biasanya berupa bitmap (PNG,
JPEG, WebP, GIF) pada resolusi layar, atau file SVG yang tetap tajam di ukuran
apa pun. Halaman-halaman ini menjelaskan cara mengekspornya satu per satu dan
cara mengekspor banyak halaman dan objek sekaligus.

Objek juga dapat membawa tautan yang berfungsi di file SVG, HTML, dan PDF yang
diekspor; lihat [Tautan dan penanda](../objects/links.md).
