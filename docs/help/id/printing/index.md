# Pencetakan

TraceDraw mencetak dengan membuat PDF lembaran yang siap cetak, yang dikirim
penampil sistem Anda ke printer. Halaman-halaman ini menjelaskan kotak dialog
Cetak dan pratinjaunya, cara menggabungkan data ke dalam desain untuk mencetak
banyak versi, cara memeriksa gambar sebelum dicetak, dan cara merampungkan
spanduk dengan bingkai dan mata ayam.
