# Teks

TraceDraw memiliki dua jenis teks. **Teks artistik** adalah satu baris, atau
beberapa baris, yang ditempatkan di sebuah titik: judul, label, logo. **Teks
paragraf** mengalir di dalam bingkai dan terlipat di tepinya: teks isi, kolom,
daftar. Keduanya dapat diformat karakter demi karakter, dipasang pada jalur,
dan diperiksa ejaannya.

Halaman-halaman ini menjelaskan cara menambah dan memformat teks, menata
paragraf, memilih font dan karakter khusus, serta memakai alat tulis.
