# Halaman dan tata letak

Sebuah gambar dapat memiliki banyak halaman, masing-masing dengan ukuran dan
orientasinya sendiri. Halaman-halaman ini menjelaskan cara menambah, menata,
dan menomori halaman, mengatur opsi dokumen (ukuran halaman, tata letak, latar,
bleed, penggaris, kisi, dan garis bantu), menempatkan garis bantu,
menjepretkan objek ke tempatnya, dan membaca properti gambar.
