# Warna, isian, dan transparansi

Setiap objek dapat memiliki isian di dalamnya dan garis luar di sepanjang
tepinya. Halaman-halaman ini menjelaskan cara memilih warna dari palet dan
panel [[docker.color]], jenis isian (warna rata, gradien, pola, tekstur, atau
jaring), cara membuat objek tembus pandang, dan cara menjaga warna tetap
konsisten dengan gaya warna, tinta spot, dan manajemen warna.
