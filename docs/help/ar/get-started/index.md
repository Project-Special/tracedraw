# البدء

تعرّف هذه الصفحات بـ TraceDraw: أجزاء النافذة، وكيفية إنشاء الرسومات وفتحها
وحفظها، وكيفية التنقل في الرسم والتراجع عن العمل، وأين تجد المساعدة أثناء
الرسم.

يعمل TraceDraw على Windows وmacOS وLinux، وفي متصفح الويب دون تثبيت أي شيء.
وكلاهما البرنامج نفسه؛ وتشرح صفحة [إصدار المتصفح](browser-version.md) الفروق
القليلة لإصدار المتصفح.
