# النص

في TraceDraw نوعان من النص. **النص الفني** سطر أو بضعة أسطر توضع عند نقطة:
العناوين والتسميات والشعارات. **نص الفقرة** يتدفق داخل إطار ويلتف عند حوافه: نص
المتن والأعمدة والقوائم. ويمكن تنسيق الاثنين حرفًا حرفًا، وتركيبهما على مسارات،
وتدقيق إملائهما.

تشرح هذه الصفحات كيفية إضافة النص وتنسيقه، وتخطيط الفقرات، واختيار الخطوط
والأحرف الخاصة، واستخدام أدوات الكتابة.
