# القوالب والأنماط

توفّر القوالب والأنماط عملًا كنت ستكرره. **القالب** رسم جاهز تبدأ منه.
**النمط** مجموعة مسماة من التعبئة والحد والشفافية تظل مرتبطة بالكائنات التي
تستخدمها، فيعيد تغيير واحد تنسيقها كلها. وتحدد **الخصائص الافتراضية** مظهر
الكائنات الجديدة.

تشرح صفحة [أنماط الألوان](../color/color-styles.md) أنماط الألوان، التي تعمل
بالطريقة نفسها للألوان المفردة.
