# رسومات الويب

رسومات صفحات الويب والتطبيقات والشاشات عادة صور نقطية (PNG وJPEG وWebP وGIF)
بدقة الشاشة، أو ملفات SVG تبقى حادة بأي حجم. تشرح هذه الصفحات كيفية تصديرها
واحدًا تلو الآخر، وكيفية تصدير صفحات وكائنات كثيرة دفعة واحدة.
