# الكائنات والرموز والطبقات

كل شكل وخط ونص وصورة في الرسم كائن. تشرح هذه الصفحات كيفية تحديد الكائنات
ونقلها وتغيير حجمها وتدويرها ومحاذاتها، وكيفية ترتيبها وتجميعها وتنظيمها في
طبقات، وكيفية إعادة استخدامها رموزًا.

وتتناول أيضًا الكائنات ذات المهام الخاصة: الجداول، والرموز الشريطية ورموز QR،
والتعليقات، والبيانات التي ترفقها بالكائنات.
