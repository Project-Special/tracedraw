# الصور النقطية

الصور النقطية صور مكونة من بكسلات، مثل الصور الفوتوغرافية والمستندات الممسوحة.
يضعها TraceDraw في الرسومات، ويغيّر وضع ألوانها وحجمها، ويقوّمها، ويحجب ألوانًا
منها، ويطبق عليها التأثيرات، ويتتبعها إلى أشكال. ويحوّل أيضًا الكائنات المتجهة
إلى صور نقطية.

لإحضار صورة، استخدم [[menu.file > menu.file.import]]؛ انظر
[استيراد الملفات](../file-formats/import.md). عند تحديد صورة نقطية، يضم شريط
الخصائص أوامر الصور النقطية: التحرير والقص والتتبع والتقويم وإعادة التشكيل.
وللتأثيرات، انظر [تأثيرات الصور النقطية](../effects/bitmap-effects.md).
