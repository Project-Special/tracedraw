# الألوان والتعبئة والشفافية

يمكن أن تكون لكل كائن تعبئة في داخله وحد على امتداد حافته. تشرح هذه الصفحات
كيفية اختيار الألوان من لوحات الألوان ومن لوحة [[docker.color]]، وأنواع التعبئة
(لون موحد، أو تدرج، أو نقش، أو نسيج، أو شبكة)، وكيفية جعل الكائنات شفافة،
وكيفية الحفاظ على اتساق الألوان بأنماط الألوان والأحبار الموضعية وإدارة
الألوان.
