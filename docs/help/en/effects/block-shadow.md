# Block shadows

A block shadow is a solid shadow that runs straight out from an object, as if
the object were a thick block. It is drawn below the object as one filled
shape, which suits signs and cut vinyl.

## To add a block shadow {#create}

1. Choose the [[tool.block_shadow]] tool from the Effects flyout.
2. Drag from an object in the direction the shadow should go.

## Settings {#settings}

On the property bar:

- **Depth**: how far the shadow reaches.
- **Direction**: its angle, 0 being to the right, counterclockwise.
- **Color**: 60% black at first.
- **Gap**: a clear band between the object and the shadow (0 at first).
- **Clear block shadow** removes the effect.

With a shadowed object selected, the fields change its shadow; otherwise they
set the next one.
