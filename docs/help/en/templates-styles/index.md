# Templates and styles

Templates and styles save work you would otherwise repeat. A **template** is
a ready-made drawing to start from. A **style** is a named set of fill,
outline and transparency that stays linked to the objects that use it, so one
change restyles them all. The **default properties** decide how new objects
look.

Color styles, which work the same way for single colors, are explained in
[Color styles](../color/color-styles.md).
