# Get started

These pages introduce TraceDraw: the parts of the window, how to create,
open and save drawings, how to move around a drawing and undo your work,
and where to find help while you draw.

TraceDraw runs on Windows, macOS and Linux, and in a web browser with
nothing to install. Both are the same program; the few differences of the
browser version are explained in [The browser version](browser-version.md).
