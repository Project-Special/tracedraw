# Web graphics

Graphics for web pages, apps and screens are usually bitmaps (PNG, JPEG,
WebP, GIF) at screen resolution, or SVG files that stay sharp at any size.
These pages explain how to export them one at a time, and how to export many
pages and objects at once.

Objects can also carry links that work in exported SVG, HTML and PDF files;
see [Links and bookmarks](../objects/links.md).
