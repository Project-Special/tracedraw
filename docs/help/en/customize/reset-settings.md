# Resetting settings

If your setup gets into a muddle, you can put every preference back to how
TraceDraw comes. Your drawings are never touched.

## To reset every setting {#reset}

- Choose [[options.reset_all]] on the [[options.general]] page of
  [[menu.tools > menu.tools.options > menu.tools.options_global]].
- Or press <kbd>F8</kbd> while the splash screen shows as TraceDraw starts.

TraceDraw asks first. **Reset** puts back every preference, but keeps the list
of recent drawings, the last folder and the size of the window.
[[dialog.cancel]] changes nothing.

![The question before resetting the settings](../../img/customize-reset-settings.png)

To reset only some things: the toolbox and the bars have their own reset
commands (see [The workspace](../get-started/workspace.md#arranging)), and
choosing a built-in workspace sets its own bars (see
[Workspaces](workspaces.md)).
