# Customize and automate

TraceDraw can be set up the way you work: options for the program and for
each tool, the look of the interface, keyboard shortcuts, bars and
workspaces. You can also automate work with scripts, connect an AI service to
draw from a description, and track the time spent on a drawing.

The options are in [[menu.tools > menu.tools.options]]: each item opens its own
dialog box. Changes show at once; [[dialog.ok]] keeps them and
[[dialog.cancel]] puts everything back. The **?** button opens the page of
this Help about the options page on show.
