# 瀏覽器版本

您可以[在網頁瀏覽器中使用 TraceDraw](https://igtoth.github.io/tracedraw/)，不需安裝任何東西。它與桌面版是同一個程式，只是為瀏覽器建置，因此選單、工具和檔案都相同。

## 與桌面版的差異 {#differences}

- **速度。** 大型繪圖、繁重的效果、描繪、馬賽克和大型匯出會比較慢，並且在完成之前讓頁面保持忙碌。桌面版則以全速執行。
- **檔案。** 開啟和匯入會使用瀏覽器的檔案選擇器；儲存、匯出和列印則會下載檔案。不會列出最近的繪圖，因為瀏覽器無法重新開啟已上傳的檔案。
- **字型。** 頁面自帶字型，並會在您的文字第一次需要時擷取更多字型。
- **設定**會保存在該台電腦的該瀏覽器中。
- **按鍵。** 當繪圖取得焦點時，程式的快速鍵會送到 TraceDraw 而不是瀏覽器，但剪貼簿按鍵、重新載入和瀏覽器的開發人員工具除外。<kbd>Ctrl+N</kbd>、<kbd>Ctrl+T</kbd> 和 <kbd>Ctrl+W</kbd> 一律由瀏覽器使用，因此請使用 [[menu.file]] 選單來建立和關閉繪圖。
- **螢幕。** 它適合搭配滑鼠和鍵盤的桌面瀏覽器。在平板電腦上，請使用觸控工作區（請參閱[工作區](../customize/workspaces.md)）；手機螢幕太小，不適合編輯。
- **更新。** 瀏覽器版本永遠是最新版；不需要安裝任何東西。自動備份和工作階段復原是桌面版的功能。
