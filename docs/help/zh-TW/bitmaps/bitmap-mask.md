# 從點陣圖中遮罩色彩

[[docker.bitmap_mask]] 面板可隱藏或保留點陣圖中所選色彩的像素，例如讓白色背景變成透明。使用 [[menu.bitmaps > menu.bitmaps.bitmap_mask]] 開啟它。

![點陣圖遮色片面板](../../img/bitmaps-bitmap-mask.png)

## 遮罩色彩 {#mask}

1. 選取一個點陣圖。
2. 將色彩挑選到十個色彩欄位中：
   - 按一下滴管，然後按一下點陣圖中的色彩；每個色彩都會填入選取的欄位並將其勾選；
   - 或按一下**從點陣圖選取色彩**，以點陣圖最常用的十種色彩填入各欄位。
3. 選取一個欄位並設定其**容許度**（0 到 100%）：像素的色彩與欄位色彩可以相差多少，仍然視為相符。
4. 選擇**隱藏選取的色彩**（相符的像素會變成透明）或**顯示選取的色彩**（只保留相符的像素，此為預設）。
5. 按一下 [[docker.apply]]。

**儲存遮色片**和**開啟遮色片**會將各欄位保存在 `.msk` 檔案中；**刪除**會清空選取的欄位。每個點陣圖的變更都是一個復原步驟。
