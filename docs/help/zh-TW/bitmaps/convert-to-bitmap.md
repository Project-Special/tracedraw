# 將物件轉換為點陣圖

[[menu.bitmaps > menu.bitmaps.convert_to_bitmap]]（也可使用 [[menu.object > menu.object.convert_to_bitmap]]）會將選取的物件轉換為一個點陣圖。可用來將複雜的圖稿平面化，或為物件套用點陣圖效果做準備。這是一個復原步驟。

![轉換為點陣圖對話方塊](../../img/bitmaps-convert-to-bitmap.png)

## 設定 {#settings}

- **解析度**：從清單中選擇（72 到 600 dpi）或輸入值（36 到 2400；預設為 300）。
- **色彩模式**：黑白（1 位元）、灰階（8 位元）、調色盤式（8 位元）、RGB 色彩（24 位元，預設）或 CMYK 色彩（32 位元）。
- **混色**：適用於黑白和調色盤式，以混合網點來表現缺少的色調。
- **永遠套印黑色**：點陣圖的黑色會套印在下方的色彩上。
- **消除鋸齒**（預設開啟）：平滑的邊緣；關閉時會產生生硬的像素邊緣。
- **透明背景**（預設開啟）；關閉時會將物件放在白色背景上。

對話方塊會顯示點陣圖未壓縮時的大小。
