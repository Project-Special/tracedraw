# ওয়েব গ্রাফিক্স

ওয়েব পৃষ্ঠা, অ্যাপ ও স্ক্রিনের গ্রাফিক্স সাধারণত স্ক্রিন রেজোলিউশনের বিটম্যাপ
(PNG, JPEG, WebP, GIF), বা যেকোনো আকারে স্পষ্ট থাকা SVG ফাইল। এই পৃষ্ঠাগুলি
ব্যাখ্যা করে কীভাবে সেগুলি একটি একটি করে এক্সপোর্ট করবেন এবং কীভাবে অনেক পৃষ্ঠা ও
অবজেক্ট একসঙ্গে এক্সপোর্ট করবেন।

অবজেক্টে এমন লিঙ্কও থাকতে পারে যা এক্সপোর্ট করা SVG, HTML ও PDF ফাইলে কাজ করে;
দেখুন [লিঙ্ক ও বুকমার্ক](../objects/links.md)।
