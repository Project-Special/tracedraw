# শুরু করুন

এই পৃষ্ঠাগুলি TraceDraw-এর পরিচয় দেয়: জানালার অংশগুলি, অঙ্কন তৈরি, খোলা ও
সংরক্ষণ, অঙ্কনের মধ্যে চলাফেরা ও কাজ পূর্বাবস্থায় ফেরানো, এবং আঁকার সময়
সাহায্য কোথায় পাবেন।

TraceDraw Windows, macOS ও Linux-এ এবং কিছু ইনস্টল না করেই ওয়েব ব্রাউজারে চলে।
দুটিই একই প্রোগ্রাম; ব্রাউজার সংস্করণের অল্প কিছু পার্থক্য
[ব্রাউজার সংস্করণ](browser-version.md)-এ ব্যাখ্যা করা হয়েছে।
