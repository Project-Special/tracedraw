# মুদ্রণ

TraceDraw শিটগুলির মুদ্রণ-প্রস্তুত PDF তৈরি করে মুদ্রণ করে, যা আপনার সিস্টেমের
ভিউয়ার প্রিন্টারে পাঠায়। এই পৃষ্ঠাগুলি মুদ্রণ ডায়ালগ বক্স ও তার প্রিভিউ, অনেক
সংস্করণ মুদ্রণের জন্য ডিজাইনে ডেটা মার্জ করা, মুদ্রণের আগে অঙ্কন পরীক্ষা করা, এবং
ব্যানারে বর্ডার ও গ্রোমেট দিয়ে কাজ শেষ করা ব্যাখ্যা করে।
