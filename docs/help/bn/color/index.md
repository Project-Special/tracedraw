# রং, ফিল ও স্বচ্ছতা

প্রতিটি অবজেক্টের ভেতরে ফিল এবং প্রান্ত বরাবর আউটলাইন থাকতে পারে। এই
পৃষ্ঠাগুলি ব্যাখ্যা করে প্যালেট ও [[docker.color]] প্যানেল থেকে কীভাবে রং বাছবেন,
ফিলের ধরন (একরঙা, গ্রেডিয়েন্ট, প্যাটার্ন, টেক্সচার বা মেশ), কীভাবে অবজেক্ট স্বচ্ছ
করবেন, এবং রং স্টাইল, স্পট কালি ও রং ব্যবস্থাপনা দিয়ে কীভাবে রং সামঞ্জস্যপূর্ণ
রাখবেন।
