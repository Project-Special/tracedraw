# Efekty specjalne

Efekty zmieniają wygląd obiektu bez zmiany samego obiektu: przejście wypełnia
przestrzeń między dwoma obiektami, kontur rysuje wokół obiektu pierścienie,
obwiednia go wygina, wytłoczenie nadaje mu bryłę, cień odrywa go od strony.
Większość efektów jest **dynamiczna**: obiekt zachowuje swój kształt, a efekt
jest z niego rysowany, więc można go w każdej chwili zmienić lub usunąć.

Efekty znajdują się w menu [[menu.effects]], w wysuwanym menu Efekty
przybornika i we własnych panelach. [Efekty bitmapowe](bitmap-effects.md)
zmieniają piksele obrazów lub obiektów rysowanych jako obrazy.
