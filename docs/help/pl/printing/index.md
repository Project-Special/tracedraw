# Drukowanie

TraceDraw drukuje, tworząc gotowy do druku plik PDF z arkuszami, który
przeglądarka systemu wysyła do drukarki. Te strony objaśniają okno Drukuj i
jego podgląd, scalanie danych z projektem, aby wydrukować wiele wersji,
sprawdzanie rysunku przed drukiem oraz wykańczanie banerów obramowaniem i
oczkami.
