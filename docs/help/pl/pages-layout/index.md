# Strony i układ

Rysunek może mieć wiele stron, każdą z własnym rozmiarem i orientacją. Te
strony objaśniają dodawanie, porządkowanie i numerowanie stron, ustawianie
opcji dokumentu (rozmiar strony, układ, tło, spad, linijki, siatka i
prowadnice), umieszczanie prowadnic, przyciąganie obiektów i odczytywanie
właściwości rysunku.
