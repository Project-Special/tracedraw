# Pierwsze kroki

Te strony przedstawiają TraceDraw: części okna, tworzenie, otwieranie i
zapisywanie rysunków, poruszanie się po rysunku i cofanie zmian oraz miejsca,
gdzie podczas rysowania znajdziesz pomoc.

TraceDraw działa w systemach Windows, macOS i Linux oraz w przeglądarce
internetowej bez instalowania czegokolwiek. To ten sam program; nieliczne
różnice wersji w przeglądarce opisuje
[Wersja w przeglądarce](browser-version.md).
