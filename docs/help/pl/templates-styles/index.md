# Szablony i style

Szablony i style oszczędzają pracę, którą trzeba by powtarzać. **Szablon** to
gotowy rysunek, od którego się zaczyna. **Styl** to nazwany zestaw
wypełnienia, konturu i przezroczystości, który pozostaje połączony z obiektami,
które go używają, więc jedna zmiana odświeża je wszystkie. **Właściwości
domyślne** decydują o wyglądzie nowych obiektów.

Style kolorów, które działają tak samo dla pojedynczych kolorów, opisuje strona
[Style kolorów](../color/color-styles.md).
