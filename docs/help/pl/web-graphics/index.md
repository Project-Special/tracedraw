# Grafika internetowa

Grafika do stron internetowych, aplikacji i ekranów to zwykle bitmapy (PNG,
JPEG, WebP, GIF) w rozdzielczości ekranu lub pliki SVG, które pozostają ostre w
każdym rozmiarze. Te strony objaśniają eksportowanie ich pojedynczo i
eksportowanie wielu stron i obiektów naraz.

Obiekty mogą też zawierać łącza działające w wyeksportowanych plikach SVG, HTML
i PDF; zobacz [Łącza i zakładki](../objects/links.md).
