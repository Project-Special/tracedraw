# Kolory, wypełnienia i przezroczystości

Każdy obiekt może mieć wypełnienie w środku i kontur wzdłuż krawędzi. Te
strony objaśniają wybieranie kolorów z palet i panelu [[docker.color]], rodzaje
wypełnień (jednolity kolor, gradient, deseń, tekstura lub siatka), nadawanie
obiektom przezroczystości oraz utrzymywanie spójnych kolorów za pomocą stylów
kolorów, kolorów dodatkowych i zarządzania kolorami.
