# Bitmapy

Bitmapy to obrazy złożone z pikseli, takie jak zdjęcia i skany. TraceDraw
umieszcza je w rysunkach, zmienia ich tryb kolorów i rozmiar, prostuje je,
maskuje kolory, nakłada efekty i wektoryzuje je w kształty. Zamienia też
obiekty wektorowe w bitmapy.

Aby wstawić obraz, użyj [[menu.file > menu.file.import]]; zobacz
[Importowanie plików](../file-formats/import.md). Gdy zaznaczona jest bitmapa,
pasek właściwości zawiera polecenia bitmap: edycję, kadrowanie, wektoryzację,
prostowanie i ponowne próbkowanie. O efektach zobacz
[Efekty bitmapowe](../effects/bitmap-effects.md).
