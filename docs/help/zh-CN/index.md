# 欢迎使用 TraceDraw 帮助

TraceDraw 是一款免费的开源矢量绘图程序。你可以用它绘制插画、标志、图表、版面
和印刷品，它们由在任何尺寸下都保持清晰的形状、线条和文字组成，还可以与位图
结合。同一个程序可在 Windows、macOS 和 Linux 以及网页浏览器中运行。

本帮助一步步说明如何在 TraceDraw 中完成工作，以及每个对话框、面板和工具的
作用。

## 本帮助的组织方式 {#organization}

左侧的目录按照工作的顺序排列：

- **入门** 介绍工作区、新建绘图、打开和保存。
- **线条、形状和轮廓**、**对象、符号和图层** 以及 **颜色、填充和透明度**
  介绍绘制和排列对象。
- **特殊效果**、**文本**、**模板和样式**、**页面和版面** 以及 **位图**
  涵盖其余的绘图工作。
- **打印**、**网页图形** 和 **文件格式** 介绍如何把作品从 TraceDraw 输出。
- **自定义和自动化** 介绍选项、工作区、脚本和 AI 功能，**参考** 列出每个
  菜单命令、工具、面板和键盘快捷键。

使用 **搜索** 选项卡可按页面中的任意字词查找页面，使用顶部的语言列表可用另
一种语言阅读同一页面。

## 在 TraceDraw 中获取帮助 {#in-the-app}

- 按 <kbd>F1</kbd> 打开眼前内容的页面：打开的对话框，否则是显示的面板，再否则
  是当前工具。
- 单击对话框或选项页底部的 **?** 按钮，打开它的页面。
- 选择 [[menu.help > menu.help.help_topics]] 打开本页。
- [[docker.hints]] 面板会在你工作时说明当前工具；其中的 [[hint.learn_more]]
  链接会打开该工具在这里的页面。请参阅 [提示](get-started/hints.md)。

页面会在网页浏览器中以 TraceDraw 设置的语言打开。
