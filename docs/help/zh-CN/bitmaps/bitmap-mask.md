# 遮罩位图中的颜色

[[docker.bitmap_mask]] 面板可以隐藏或保留位图中所选颜色的像素，例如让白色背景变为透明。使用 [[menu.bitmaps > menu.bitmaps.bitmap_mask]] 打开它。

![位图遮罩面板](../../img/bitmaps-bitmap-mask.png)

## 遮罩颜色 {#mask}

1. 选择一个位图。
2. 把颜色选入十个颜色槽：
   - 单击滴管，再单击位图中的颜色；每种颜色都会填入所选的颜色槽并将其勾选；
   - 或单击 **从位图选择颜色**，用位图中使用最多的十种颜色填满颜色槽。
3. 选择一个颜色槽并设置其 **容差**（0 到 100%）：像素颜色与该颜色槽颜色相差多少仍算匹配。
4. 选择 **隐藏选定项**（匹配的像素变为透明）或 **显示选定项**（起初只保留匹配的像素）。
5. 单击 [[docker.apply]]。

**保存遮罩** 和 **打开遮罩** 将颜色槽保存在 `.msk` 文件中；**删除** 清空所选颜色槽。每个位图的更改为一个撤消步骤。
