# 块阴影

块阴影是从对象笔直延伸出去的实心阴影，好像对象是一块厚实的块体。它作为一个填充形状绘制在对象下方，适合标牌和刻字贴膜。

## 添加块阴影 {#create}

1. 从效果展开工具栏中选择 [[tool.block_shadow]] 工具。
2. 从对象朝阴影的方向拖动。

## 设置 {#settings}

在属性栏上：

- **深度**：阴影延伸的距离。
- **方向**：其角度，0 为向右，按逆时针方向计算。
- **颜色**：起初为 60% 黑色。
- **间隙**：对象和阴影之间的空白带（起初为 0）。
- **清除块阴影** 删除该效果。

选中带阴影的对象时，这些字段更改其阴影；否则它们设置下一个阴影。
