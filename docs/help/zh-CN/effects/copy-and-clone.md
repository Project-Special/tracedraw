# 复制和克隆效果

与其重新设置效果，不如从已经具有该效果的对象复制它。

## 复制效果 {#copy}

1. 选择要获得该效果的对象。
2. 选择 [[menu.object > menu.object.copy_effect]] 和效果类型：[[menu.object.copy_shadow_from]]、[[menu.object.copy_transparency_from]]、[[menu.object.copy_envelope_from]]、[[menu.object.copy_perspective_from]]、[[menu.object.copy_distortion_from]]、[[menu.object.copy_extrude_from]]、[[menu.object.copy_contour_from]]、[[menu.object.copy_blend_from]]、[[menu.object.copy_lens_from]]、[[menu.object.copy_bevel_from]] 或 [[menu.object.copy_block_shadow_from]]。
3. 单击要从中复制的对象。右键单击取消。

效果会适应每个对象：封套或透视会拉伸到对象的大小，变形会将其中心保持在对象内的相同位置。如果你单击的对象没有这种效果，则不做任何更改，状态栏会给出说明。复制为一个撤消步骤。

## 克隆效果 {#clone}

[[menu.object > menu.object.clone_effect]] 复制另一个对象的阴影（[[menu.object.clone_shadow_from]]）或透明度（[[menu.object.clone_transparency_from]]），并持续跟随它：更改源对象，克隆也随之改变，直到你编辑克隆自身的效果为止。

[[menu.edit > menu.edit.clone]] 克隆整个对象，[[menu.edit.copy_properties_from]] 复制另一个对象的填充、轮廓或文本属性。
