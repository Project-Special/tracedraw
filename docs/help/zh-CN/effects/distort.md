# 变形

[[tool.distort]] 工具以三种方式弯曲对象的轮廓：**推拉**（尖刺或花瓣）、**拉链**（锯齿）和 **扭曲**（旋涡）。它是一种实时效果：你可以随时更改、移动或删除变形，对象保留其自身的轮廓。

## 使对象变形 {#create}

1. 从效果展开工具栏中选择 [[tool.distort]] 工具。
2. 在属性栏上选择类型。
3. 在对象上拖动。变形以你开始拖动的位置为中心。
   - **推拉**：向右拖动将节点向外推（带有凹边的尖刺形状），向左拖动将节点向内拉（圆润的花瓣）。
   - **拉链**：拖得越远，锯齿越高。
   - **扭曲**：绕起点拖动；整圈会被计入。

所选变形的中心显示为菱形：拖动它可移动中心。再次拖动会替换变形；一个对象最多有一个变形。群组和位图不会变形。

## 变形设置 {#settings}

属性栏显示并更改所选变形：

- 类型：**推拉**、**拉链** 或 **扭曲**（选择另一种类型会更改所选变形）；
- 推拉的 **振幅**（-200 到 200，起初为 20）；
- 拉链的 **振幅**（0 到 100 mm，起初为 2 mm）和 **频率**（每个线段的锯齿数，起初为 6），以及 **随机**（锯齿不均匀）、**平滑**（圆润的锯齿）和 **局部**（锯齿离中心越远越小）；
- 扭曲的 **顺时针** 或 **逆时针**、整圈 **旋转** 数以及额外的 **度数**。

[[menu.object > menu.object.clear_effect]] 删除变形。
