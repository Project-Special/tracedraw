# 工作区

工作区是窗口的设置方式：显示哪些栏以及它们的位置、工具箱、键盘快捷键、调色板选项和界面外观。在 [[menu.window > menu.window.workspace]] 中，或在 [[menu.tools > menu.tools.options > menu.tools.options_workspaces]] 的 [[options.workspace]] 页面上选择一个工作区。

![工作区选项](../../img/customize-workspaces.png)

## 内置工作区 {#built-in}

- [[menu.window.workspace_default]]：常用设置。
- [[menu.window.workspace_lite]]：栏更少，适合初次使用。
- [[menu.window.workspace_classic]]、[[menu.window.workspace_illustration]] 和 [[menu.window.workspace_page_layout]]：适合这些工作类型的栏和面板。
- [[menu.window.workspace_touch]]：用于触摸屏。界面绘制得更大，标尺、面板和状态栏被隐藏，使用任何工具时都可以用两根手指平移，捏合手指缩放。绘图保持其实际大小。

## 保留的内容 {#kept}

你更改的一切都会在 TraceDraw 关闭时保留，并在下次启动时恢复：选项、每个栏的位置以及显示哪些栏、每个工具箱组显示的工具、打开的面板、单位、贴齐、新对象采用的设置以及窗口显示的内容。

## 导出和导入你的设置 {#export-import}

要将你的设置带到另一台计算机，或妥善保存它：

1. 在 [[options.workspace]] 页面的 [[options.workspace_transfer]] 下，勾选要包含的部分：键盘快捷键；工具栏、工具箱和状态栏；调色板选项；外观。
2. 单击 [[options.workspace_export]] 并保存 `.tdws` 文件。
3. 在另一台计算机上，单击 [[options.workspace_import]] 并选择该文件。只应用你勾选的部分。

[[menu.window > menu.window.workspace > menu.window.workspace_export]] 和 [[menu.window.workspace_import]] 对所有部分执行相同的操作。
