# 时间跟踪

时间跟踪器按任务记录你在绘图上花费的时间，并将记录保存在绘图中（在 `.tdraw` 文件中）。只有你在工作时才计时：空闲几分钟后，时钟会等待，你的下一个操作会使其再次开始。

## 时间跟踪工具栏 {#toolbar}

[[menu.window > menu.window.toolbars > menu.window.toolbar_time_tracker]] 显示一个栏，其中有：

- 任务列表，用于选择活动任务或添加新任务；
- 活动任务的时间；
- 录制和暂停按钮；
- 指示灯：计时时为红色，空闲时为琥珀色，暂停或没有任务时为灰色；
- 所有任务的总计；
- 一个打开对话框的按钮。

在没有任务的绘图上启动时钟会添加“任务 1”。

## 时间跟踪对话框 {#dialog}

[[menu.tools > menu.tools.time_tracker]] 列出各任务及其时间、开始和结束时间，以及总计。

![时间跟踪对话框](../../img/customize-time-tracker.png)

- **新建任务**、**删除**、**设为活动** 和 **重置时间** 作用于所选任务。双击任务可将其设为活动任务。
- **录制** 和 **暂停** 启动和停止时钟。
- 编辑所选任务的 **名称**、**时间**（例如 `1:30:00`、`1:30` 或 `1.5` 小时）、**开始** 和 **结束**（例如 `2026-10-19 14:30`）。
- **无输入 N 分钟后停止计时** 设置空闲时间（起初为 5 分钟）。
- **导出 CSV** 和 **导出文本** 保存记录，用于电子表格或报告。

记录时间不是对绘图的编辑：它不产生撤消步骤。记录随绘图的下一次保存而保存。
