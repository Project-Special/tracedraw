# 重置设置

如果你的设置变得混乱，可以将所有首选项恢复为 TraceDraw 的初始状态。你的绘图永远不会受到影响。

## 重置所有设置 {#reset}

- 在 [[menu.tools > menu.tools.options > menu.tools.options_global]] 的 [[options.general]] 页面上选择 [[options.reset_all]]。
- 或在 TraceDraw 启动、显示启动屏幕时按 <kbd>F8</kbd>。

TraceDraw 会先询问。**重置** 恢复所有首选项，但保留最近绘图的列表、上次使用的文件夹和窗口大小。[[dialog.cancel]] 不做任何更改。

![重置设置前的询问](../../img/customize-reset-settings.png)

只重置部分内容：工具箱和各栏有自己的重置命令（请参阅 [工作区](../get-started/workspace.md#arranging)），选择一个内置工作区会设置其自己的栏（请参阅 [工作区](workspaces.md)）。
