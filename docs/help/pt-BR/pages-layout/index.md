# Páginas e layout

Um desenho pode ter muitas páginas, cada uma com seu tamanho e orientação.
Estas páginas explicam como acrescentar, organizar e numerar páginas, definir
as opções do documento (tamanho da página, layout, fundo, sangramento, réguas,
grade e linhas-guia), colocar linhas-guia, encaixar objetos no lugar e ler as
propriedades de um desenho.
