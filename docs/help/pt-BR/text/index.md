# Texto

O TraceDraw tem dois tipos de texto. O **texto artístico** é uma linha, ou
algumas linhas, colocada em um ponto: títulos, rótulos, logotipos. O **texto de
parágrafo** corre dentro de uma moldura e quebra nas bordas: textos corridos,
colunas, listas. Os dois podem ser formatados caractere por caractere,
ajustados a caminhos e verificados quanto à ortografia.

Estas páginas explicam como acrescentar e formatar texto, compor parágrafos,
escolher fontes e caracteres especiais e usar as ferramentas de escrita.
