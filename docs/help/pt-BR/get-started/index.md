# Introdução

Estas páginas apresentam o TraceDraw: as partes da janela, como criar, abrir e
salvar desenhos, como se mover por um desenho e desfazer o que fez, e onde
encontrar ajuda enquanto desenha.

O TraceDraw funciona no Windows, no macOS e no Linux, e no navegador sem
instalar nada. Os dois são o mesmo programa; as poucas diferenças da versão
para navegador estão em [A versão para navegador](browser-version.md).
