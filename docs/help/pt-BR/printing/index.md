# Impressão

O TraceDraw imprime montando um PDF pronto para impressão das folhas, que o
visualizador do seu sistema envia à impressora. Estas páginas explicam a caixa
de diálogo Imprimir e a prévia, como mesclar dados em um desenho para imprimir
muitas versões, como verificar um desenho antes de ir para a impressão e como
finalizar faixas com borda e ilhoses.
