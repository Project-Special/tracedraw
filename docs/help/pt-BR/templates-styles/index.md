# Modelos e estilos

Modelos e estilos poupam trabalho que você repetiria. Um **modelo** é um
desenho pronto para começar. Um **estilo** é um conjunto com nome de
preenchimento, contorno e transparência que continua ligado aos objetos que o
usam, então uma alteração muda o estilo de todos. As **propriedades padrão**
decidem a aparência dos novos objetos.

Os estilos de cor, que funcionam do mesmo jeito para cores únicas, são
explicados em [Estilos de cor](../color/color-styles.md).
