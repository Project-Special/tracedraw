# Exportar para a web

[[menu.file > menu.file.export_for > menu.file.export_for_web]] abre a caixa de
diálogo Exportar preparada para telas: PNG a 96 dpi. Ela guarda as próprias
configurações, separadas de [[menu.file.export]].
[[menu.file.export_for_office]] faz o mesmo para documentos de escritório (PNG
a 150 dpi).

![A caixa de diálogo Exportar](../../img/file-formats-export.png)

## Escolher um formato {#formats}

- **PNG**: bordas nítidas e transparência; o melhor para logotipos, ícones e
  ilustrações.
- **JPEG**: arquivos pequenos para fotos; sem transparência. Defina a
  **qualidade** (1 a 100).
- **WebP**: arquivos pequenos com transparência; defina a qualidade.
- **GIF**: poucas cores, com transparência.
- **SVG**: gráficos vetoriais que ficam nítidos em qualquer tamanho e mantêm
  links e nomes de objetos.
- **HTML**: uma página web com o desenho.

## Tamanho e resolução {#size}

Para formatos de bitmap, defina a **resolução**, ou digite a **largura** ou a
**altura** em pixels: o outro lado segue as proporções da página. Para um ícone
de 32 por 32 pixels, digite 32. Com **Fundo transparente** ligado, as partes
vazias da página ficam transparentes em arquivos PNG, WebP e GIF.

**Somente selecionados** exporta apenas os objetos selecionados, recortados
neles; **Todas as páginas** exporta cada página. A prévia mostra o que será
gravado, e a caixa de diálogo estima o tamanho do arquivo.

## Antes de exportar texto {#text}

[[menu.text > menu.text.make_web_compatible]] simplifica o texto para a web.
Para exportar muitas páginas ou objetos de uma vez, veja
[O painel Exportar](export-docker.md).
