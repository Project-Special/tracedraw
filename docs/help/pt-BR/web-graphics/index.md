# Gráficos para a web

Gráficos para páginas web, aplicativos e telas normalmente são bitmaps (PNG,
JPEG, WebP, GIF) em resolução de tela, ou arquivos SVG que ficam nítidos em
qualquer tamanho. Estas páginas explicam como exportá-los um de cada vez e como
exportar muitas páginas e objetos de uma vez.

Os objetos também podem levar links que funcionam em arquivos SVG, HTML e PDF
exportados; veja [Links e marcadores](../objects/links.md).
