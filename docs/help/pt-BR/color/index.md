# Cores, preenchimentos e transparências

Todo objeto pode ter um preenchimento por dentro e um contorno na borda. Estas
páginas explicam como escolher cores nas paletas e no painel [[docker.color]],
os tipos de preenchimento (uma cor lisa, um gradiente, um padrão, uma textura ou
uma malha), como deixar objetos transparentes e como manter as cores coerentes
com estilos de cor, tintas especiais e gerenciamento de cores.
