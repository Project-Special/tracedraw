# Converter objetos em bitmaps

[[menu.bitmaps > menu.bitmaps.convert_to_bitmap]] (também
[[menu.object > menu.object.convert_to_bitmap]]) transforma os objetos
selecionados em um único bitmap. Use-o para achatar uma arte complexa ou para
preparar objetos para efeitos de bitmap. É um passo de desfazer.

![A caixa de diálogo Converter em bitmap](../../img/bitmaps-convert-to-bitmap.png)

## Configurações {#settings}

- **Resolução**: escolha na lista (72 a 600 dpi) ou digite um valor (36 a
  2400; 300 de início).
- **Modo de cor**: Preto e branco (1 bit), Tons de cinza (8 bits), Paleta
  (8 bits), Cor RGB (24 bits, de início) ou Cor CMYK (32 bits).
- **Pontilhado**: para Preto e branco e Paleta, mistura pontos para sugerir os
  tons que faltam.
- **Sempre sobreimprimir o preto**: o preto do bitmap é impresso sobre as cores
  embaixo.
- **Suavização** (ligada de início): bordas suaves; desligada dá bordas de
  pixel duras.
- **Fundo transparente** (ligado de início); desligado põe os objetos sobre
  branco.

A caixa de diálogo mostra o tamanho que o bitmap terá, sem compressão.
