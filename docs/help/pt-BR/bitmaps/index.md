# Bitmaps

Bitmaps são imagens feitas de pixels, como fotos e digitalizações. O TraceDraw
os coloca em desenhos, muda o modo de cor e o tamanho, endireita, mascara cores,
aplica efeitos e os vetoriza em formas. Também transforma objetos vetoriais em
bitmaps.

Para trazer uma imagem, use [[menu.file > menu.file.import]]; veja
[Importar arquivos](../file-formats/import.md). Com um bitmap selecionado, a
barra de propriedades tem os comandos de bitmap: editar, recortar, vetorizar,
endireitar e reamostrar. Para efeitos, veja
[Efeitos de bitmap](../effects/bitmap-effects.md).
