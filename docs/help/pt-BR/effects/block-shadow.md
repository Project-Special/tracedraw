# Sombras em bloco

Uma sombra em bloco é uma sombra sólida que sai reta de um objeto, como se o
objeto fosse um bloco grosso. Ela é desenhada abaixo do objeto como uma única
forma preenchida, o que serve bem para placas e recorte em vinil.

## Para acrescentar uma sombra em bloco {#create}

1. Escolha a ferramenta [[tool.block_shadow]] no submenu Efeitos.
2. Arraste a partir de um objeto na direção em que a sombra deve ir.

## Configurações {#settings}

Na barra de propriedades:

- **Profundidade**: até onde a sombra vai.
- **Direção**: o ângulo, 0 sendo para a direita, no sentido anti-horário.
- **Cor**: 60% de preto de início.
- **Espaço**: uma faixa vazia entre o objeto e a sombra (0 de início).
- **Limpar sombra em bloco** remove o efeito.

Com um objeto com sombra selecionado, os campos mudam a sombra dele; caso
contrário, definem a próxima.
