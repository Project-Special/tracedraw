# Objetos, símbolos y capas

Cada forma, línea, texto e imagen de un dibujo es un objeto. Estas páginas
explican cómo seleccionar objetos, moverlos, cambiar su tamaño, girarlos y
alinearlos, cómo ordenarlos, agruparlos y organizarlos en capas, y cómo
reutilizarlos como símbolos.

También tratan los objetos con una función propia: tablas, códigos de barras y
QR, comentarios y los datos que se adjuntan a los objetos.
