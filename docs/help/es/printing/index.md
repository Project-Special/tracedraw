# Impresión

TraceDraw imprime creando un PDF listo para imprimir con las hojas, que el
visor de su sistema envía a la impresora. Estas páginas explican el cuadro de
diálogo Imprimir y su vista previa, cómo combinar datos en un diseño para
imprimir muchas versiones, cómo revisar un dibujo antes de imprimirlo y cómo
rematar pancartas con un borde y ojales.
