# Formatos de archivo

TraceDraw guarda su propio formato, `.tdraw`, que lo conserva todo, y también
guarda archivos `.cdr`. Abre e importa muchos otros formatos y exporta formatos
vectoriales, de mapa de bits y de impresión. Estas páginas enumeran los
formatos y explican cómo importar, exportar y publicar archivos PDF.
