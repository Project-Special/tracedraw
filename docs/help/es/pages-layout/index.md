# Páginas y diseño

Un dibujo puede tener muchas páginas, cada una con su tamaño y orientación.
Estas páginas explican cómo añadir, ordenar y numerar páginas, definir las
opciones del documento (tamaño de página, diseño, fondo, sangrado, reglas,
cuadrícula y líneas guía), colocar líneas guía, ajustar objetos a su sitio y
leer las propiedades de un dibujo.
