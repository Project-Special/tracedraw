# Gráficos web

Los gráficos para páginas web, aplicaciones y pantallas suelen ser mapas de
bits (PNG, JPEG, WebP, GIF) a resolución de pantalla, o archivos SVG que se
mantienen nítidos a cualquier tamaño. Estas páginas explican cómo exportarlos
de uno en uno y cómo exportar muchas páginas y objetos a la vez.

Los objetos también pueden llevar enlaces que funcionan en los archivos SVG,
HTML y PDF exportados; vea [Enlaces y marcadores](../objects/links.md).
