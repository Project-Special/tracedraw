# Веб-графика

Графика для веб-страниц, приложений и экранов обычно состоит из растровых
изображений (PNG, JPEG, WebP, GIF) с экранным разрешением или файлов SVG,
которые остаются чёткими при любом размере. Эти страницы объясняют, как
экспортировать их по одному и как экспортировать много страниц и объектов
сразу.

Объекты могут также содержать ссылки, которые работают в экспортированных
файлах SVG, HTML и PDF; см. [Ссылки и закладки](../objects/links.md).
