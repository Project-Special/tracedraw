# Форматы файлов

TraceDraw сохраняет в собственном формате `.tdraw`, который хранит всё, а
также сохраняет файлы `.cdr`. Он открывает и импортирует много других форматов
и экспортирует векторные, растровые и печатные форматы. Эти страницы
перечисляют форматы и объясняют импорт, экспорт и публикацию файлов PDF.
