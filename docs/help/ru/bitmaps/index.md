# Растровые изображения

Растровые изображения состоят из пикселей, как фотографии и сканы. TraceDraw
размещает их в рисунках, меняет их цветовой режим и размер, выравнивает их,
маскирует цвета, применяет эффекты и трассирует их в фигуры. Он также
превращает векторные объекты в растровые изображения.

Чтобы добавить изображение, используйте [[menu.file > menu.file.import]]; см.
[Импорт файлов](../file-formats/import.md). Когда выделено растровое
изображение, на панели свойств есть команды для него: правка, обрезка,
трассировка, выравнивание и передискретизация. Об эффектах см.
[Растровые эффекты](../effects/bitmap-effects.md).
