# Трассировка растровых изображений

Трассировка превращает растровое изображение в векторные фигуры, которые можно
редактировать, перекрашивать и масштабировать без потери качества:
отсканированный логотип, эскиз, фотографию.

## Быстрая трассировка {#quick-trace}

Выделите растровое изображение и выберите
[[menu.bitmaps > menu.bitmaps.quick_trace]]. Она использует набор параметров,
выбранный на странице [[options.bitmap_tracing]] общих параметров (по
умолчанию «Клипарт»).

## Диалоговое окно трассировки {#trace}

[[menu.bitmaps > menu.bitmaps.outline_trace]] и
[[menu.bitmaps.centerline_trace]] содержат наборы параметров; выберите один,
чтобы открыть диалоговое окно трассировки.

- **Контурная трассировка** заполняет цветовые области фигурами:
  [[menu.bitmaps.trace_line_art]], [[menu.bitmaps.trace_logo]],
  [[menu.bitmaps.trace_detailed_logo]], [[menu.bitmaps.trace_clipart]],
  [[menu.bitmaps.trace_low_quality]] и [[menu.bitmaps.trace_high_quality]].
- **Трассировка по осевой линии** следует за линиями открытыми кривыми:
  [[menu.bitmaps.trace_technical]] и [[menu.bitmaps.trace_line_drawing]].

![Диалоговое окно трассировки](../../img/bitmaps-tracing.png)

Диалоговое окно показывает изображение **до** и его трассировку **после**,
обновляя её при изменении параметров:

- кнопки наборов параметров вверху;
- **Детализация** (от 0 до 100): чем больше, тем мельче сохраняемые области;
- **Сглаживание** (от 0 до 100, по умолчанию 25): более гладкие кривые,
  меньше узлов;
- **Сглаживание углов** (от 0 до 100): более скруглённые углы;
- **Чёрно-белый** или число **Цветов** (от 1 до 256);
- **Удалить фон** (по умолчанию включено): не включает цвет фона;
- **Удалить исходное изображение** (по умолчанию выключено);
- **Предпросмотр** подсчитывает кривые полной трассировки.

Нажмите [[dialog.ok]], чтобы выполнить трассировку. Фигуры кладутся поверх
изображения, начиная с самых тёмных.
