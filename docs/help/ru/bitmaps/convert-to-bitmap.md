# Преобразование объектов в растровые изображения

[[menu.bitmaps > menu.bitmaps.convert_to_bitmap]] (также
[[menu.object > menu.object.convert_to_bitmap]]) превращает выделенные объекты
в одно растровое изображение. Используйте это, чтобы сделать плоским сложный
рисунок или подготовить объекты к растровым эффектам. Это один шаг отмены.

![Диалоговое окно «Преобразовать в растровое изображение»](../../img/bitmaps-convert-to-bitmap.png)

## Параметры {#settings}

- **Разрешение**: выберите из списка (от 72 до 600 dpi) или введите значение
  (от 36 до 2400; по умолчанию 300).
- **Цветовой режим**: чёрно-белый (1 бит), оттенки серого (8 бит), палитровый
  (8 бит), цвет RGB (24 бита, по умолчанию) или цвет CMYK (32 бита).
- **Сглаживание растра**: для чёрно-белого и палитрового режимов смешивает
  точки, чтобы передать недостающие оттенки.
- **Всегда печатать чёрный с наложением**: чёрный цвет изображения печатается
  поверх цветов под ним.
- **Сглаживание краёв** (по умолчанию включено): гладкие края; без него края
  пикселей резкие.
- **Прозрачный фон** (по умолчанию включён); без него объекты кладутся на
  белый.

Диалоговое окно показывает, каким будет размер изображения без сжатия.
