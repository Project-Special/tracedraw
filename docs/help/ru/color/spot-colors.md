# Плашечные цвета

**Плашечный цвет** это именованная краска, которая печатается со своей
отдельной формы, например металлик или фирменный цвет, вместо того чтобы
смешиваться из голубой, пурпурной, жёлтой и чёрной. Каждый рисунок хранит
список своих плашечных красок. У каждой краски есть замена из триадных
цветов, которая показывает её на экране и используется везде, где краску
применить нельзя.

## Добавление плашечной краски {#add}

1. Откройте панель [[docker.color]] и смешайте цвет, на который должна быть
   похожа краска.
2. В разделе [[docker.spot_inks]] введите [[docker.ink_name]].
3. Нажмите [[docker.new_ink]].

Имена в пределах рисунка уникальны.

## Использование плашечных красок {#use}

Список [[docker.spot_inks]] показывает каждую краску с образцом, её имя и
кнопки [[docker.fill]] и [[docker.outline]], которые применяют её к
выделенному с заданным [[docker.tint]] (от 0 до 100%, по умолчанию 100%).
Крестик в конце строки удаляет краску из списка; объекты, которые её
используют, сохраняют цвет замены.

## Цветовые справочники {#color-books}

Файл палитры может быть справочником плашечных красок (например, палитра
`.ase` с плашечными записями). Её плашечные записи открываются как плашечные
цвета с именами из справочника; применение одной из них добавляет краску в
рисунок. TraceDraw не поставляется с лицензионными цветовыми справочниками, но
имеющийся у вас справочник открывается как любая палитра.

## Плашечные цвета при печати и экспорте {#output}

- В файлах PDF каждая краска становится цветом цветоделения с её именем,
  поэтому типография получает краску.
- При печати цветоделения каждая краска получает свою форму после форм
  голубой, пурпурной, жёлтой и чёрной. См. [Печать](../printing/print.md).
- На экране и в растровых файлах, SVG и `.cdr` плашечный цвет показывается
  как его замена с его оттенком.
