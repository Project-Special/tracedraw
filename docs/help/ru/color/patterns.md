# Заливки узором

Заливка узором повторяет плитку внутри объекта. Плитка может быть
двухцветной, набором векторных объектов (полноцветный векторный узор) или
растровым изображением. Плитки привязаны к странице, поэтому они не
сдвигаются, когда вы перемещаете объект.

## Создание узора из своих объектов {#create-pattern}

1. Нарисуйте объекты, из которых состоит одна плитка, и выделите их.
2. Выберите [[menu.object > menu.object.create > menu.object.create_pattern]].
3. В диалоговом окне [[dialog.create_pattern]] выберите
   [[dialog.create_pattern_type]]: [[dialog.create_pattern_vector]] сохраняет
   объекты векторными, чёткими при любом размере;
   [[dialog.create_pattern_bitmap]] делает из них картинку.
4. Нажмите [[dialog.ok]].

![Диалоговое окно «Создать узор»](../../img/color-patterns-create-pattern.png)

Узор становится заливкой новых объектов. Чтобы задать его уже нарисованным
объектам, выберите [[docker.fill_pattern]] в разделе заливки панели
[[docker.properties]].

## Параметры узора {#settings}

В разделе заливки панели [[docker.properties]] выберите
[[docker.fill_pattern]], затем вид узора и его параметры. Для векторного узора
панель показывает, сколько объектов содержит плитка, а также её ширину и
высоту: при их изменении содержимое плитки масштабируется вместе с ней.

## Узоры в экспортированных файлах {#export}

Файлы SVG сохраняют векторные узоры векторными. Файлы PDF и EPS получают их
как картинки с разрешением экспорта, обрезанные по объекту.
