# Цвет, заливки и прозрачность

У каждого объекта может быть заливка внутри и абрис вдоль края. Эти страницы
объясняют, как выбирать цвета из палитр и панели [[docker.color]], какие бывают
заливки (сплошной цвет, градиент, узор, текстура или сетка), как сделать
объекты прозрачными и как сохранять единство цветов с помощью цветовых стилей,
плашечных красок и управления цветом.
