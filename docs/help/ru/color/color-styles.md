# Цветовые стили

**Цветовой стиль** это именованный цвет, который используют объекты рисунка.
Измените стиль, и все объекты с заливкой этим цветом тоже изменятся: так цвета
дизайна остаются согласованными, и можно быстро попробовать другие цветовые
схемы. Стили перечислены на панели [[docker.color_styles]]; откройте её через
[[menu.window > menu.window.dockers]].

![Панель «Цветовые стили»](../../img/color-color-styles.png)

## Создание цветовых стилей {#create}

- [[docker.new_from_selection]] добавляет стиль для каждого цвета заливки
  выделенных объектов, который ещё не является стилем.
- [[docker.new_color_style]] добавляет стиль из текущего цвета панели
  [[docker.color]].

## Использование и правка стилей {#edit}

Каждый стиль показывает свой цвет, имя и три кнопки:

- щёлкните цвет, чтобы изменить его: объекты с заливкой этим цветом
  последуют за ним;
- щёлкните имя, чтобы переименовать стиль;
- [[docker.fill]] заливает выделенное стилем, [[docker.outline]] окрашивает
  его абрис;
- **x** удаляет стиль (объекты сохраняют свой цвет).

## Гармонии {#harmonies}

[[docker.harmony_editor]] создаёт набор сочетающихся стилей на основе
[[docker.base_color]]:

1. Выберите [[docker.base_color]].
2. Щёлкните гармонию: [[harmony.analogous]], [[harmony.complementary]],
   [[harmony.split_complementary]], [[harmony.triadic]],
   [[harmony.tetradic]] или [[harmony.monochromatic]].

Цвета гармонии добавляются как стили, названные по её имени.
