# Печать

TraceDraw печатает, создавая готовый к печати PDF с листами, который
программа просмотра вашей системы отправляет на принтер. Эти страницы
объясняют диалоговое окно «Печать» и его предварительный просмотр, как
объединять данные с макетом, чтобы напечатать много вариантов, как проверить
рисунок перед печатью и как оформить баннеры каймой и люверсами.
