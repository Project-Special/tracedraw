# Настройка и автоматизация

TraceDraw можно настроить под свой способ работы: параметры программы и
каждого инструмента, вид интерфейса, сочетания клавиш, панели и рабочие
пространства. Можно также автоматизировать работу сценариями, подключить
сервис ИИ, который рисует по описанию, и учитывать время, потраченное на
рисунок.

Параметры находятся в [[menu.tools > menu.tools.options]]: каждый пункт
открывает своё диалоговое окно. Изменения видны сразу; [[dialog.ok]] сохраняет
их, а [[dialog.cancel]] возвращает всё как было. Кнопка **?** открывает
страницу этой справки о показанной странице параметров.
