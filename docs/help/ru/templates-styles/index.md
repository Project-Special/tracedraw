# Шаблоны и стили

Шаблоны и стили избавляют от повторной работы. **Шаблон** это готовый рисунок,
с которого начинают. **Стиль** это именованный набор заливки, абриса и
прозрачности, который остаётся связанным с объектами, где он применён, так что
одно изменение обновляет их все. **Свойства по умолчанию** определяют, как
выглядят новые объекты.

Цветовые стили, которые так же работают для отдельных цветов, описаны в
[Цветовые стили](../color/color-styles.md).
