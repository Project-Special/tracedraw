# Страницы и макет

В рисунке может быть много страниц, у каждой свой размер и ориентация. Эти
страницы объясняют, как добавлять, упорядочивать и нумеровать страницы,
настраивать параметры документа (размер страницы, макет, фон, выпуск под обрез,
линейки, сетку и направляющие), ставить направляющие, привязывать объекты и
читать свойства рисунка.
