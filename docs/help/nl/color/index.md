# Kleuren, vullingen en transparanties

Elk object kan een vulling binnenin en een omtrek langs de rand hebben. Deze
pagina's leggen uit hoe u kleuren kiest uit de paletten en het paneel
[[docker.color]], welke soorten vulling er zijn (een egale kleur, een
kleurverloop, een patroon, een textuur of een maas), hoe u objecten
doorzichtig maakt en hoe u kleuren consistent houdt met kleurstijlen,
steunkleuren en kleurbeheer.
