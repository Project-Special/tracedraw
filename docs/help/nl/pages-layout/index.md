# Pagina's en lay-out

Een tekening kan veel pagina's hebben, elk met een eigen formaat en stand. Deze
pagina's leggen uit hoe u pagina's toevoegt, ordent en nummert, de
documentopties instelt (paginaformaat, lay-out, achtergrond, afloop,
linialen, raster en hulplijnen), hulplijnen plaatst, objecten laat uitlijnen
en de eigenschappen van een tekening leest.
