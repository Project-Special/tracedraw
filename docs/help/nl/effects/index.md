# Speciale effecten

Effecten veranderen hoe een object eruitziet zonder het object zelf te
veranderen: een overvloeiing vult de ruimte tussen twee objecten, een contour
tekent ringen om een object, een envelop buigt het, een extrusie laat het
massief lijken, een schaduw tilt het van de pagina. De meeste effecten zijn
**dynamisch**: het object houdt zijn eigen vorm, en het effect wordt ervan
afgeleid, zodat u het effect altijd kunt wijzigen of verwijderen.

De effecten staan in het menu [[menu.effects]], in het uitklapmenu Effecten
van de gereedschapskist en in eigen panelen.
[Bitmapeffecten](bitmap-effects.md) veranderen de pixels van afbeeldingen, of
van objecten die als afbeelding worden getekend.
