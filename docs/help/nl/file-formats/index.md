# Bestandsindelingen

TraceDraw slaat op in zijn eigen indeling, `.tdraw`, die alles bewaart, en
slaat ook `.cdr`-bestanden op. Het opent en importeert veel andere indelingen
en exporteert vector-, bitmap- en drukindelingen. Deze pagina's noemen de
indelingen en leggen importeren, exporteren en publiceren naar PDF uit.
