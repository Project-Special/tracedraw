# Sjablonen en stijlen

Sjablonen en stijlen besparen werk dat u anders zou herhalen. Een **sjabloon**
is een kant-en-klare tekening om mee te beginnen. Een **stijl** is een
benoemde set van vulling, omtrek en transparantie die gekoppeld blijft aan de
objecten die hem gebruiken, zodat één wijziging ze allemaal aanpast. De
**standaardeigenschappen** bepalen hoe nieuwe objecten eruitzien.

Kleurstijlen, die voor losse kleuren op dezelfde manier werken, worden
uitgelegd in [Kleurstijlen](../color/color-styles.md).
