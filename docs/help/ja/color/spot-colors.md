# 特色

**特色** は、シアン、マゼンタ、イエロー、ブラックを混ぜて作るのではなく、専用の版で印刷される名前付きのインキです。メタリックやブランドカラーなどがあります。各図面は特色インキの一覧を持ちます。どのインキにもプロセスカラーでできた代替色があり、画面での表示や、インキを使えないところで使われます。

## 特色インキを追加する {#add}

1. [[docker.color]] パネルを開き、インキの見た目となる色を調合します。
2. [[docker.spot_inks]] の下で [[docker.ink_name]] を入力します。
3. [[docker.new_ink]] をクリックします。

名前は図面の中で重複できません。

## 特色インキを使う {#use}

[[docker.spot_inks]] の一覧には、各インキが色見本、名前、[[docker.fill]] と [[docker.outline]] のボタンとともに表示されます。ボタンは、設定した [[docker.tint]] (0 から 100%、最初は 100%) でインキを選択範囲に適用します。行の末尾の × は一覧からインキを削除します。そのインキを使っているオブジェクトは代替色を保ちます。

## カラーブック {#color-books}

パレットファイルは特色インキのブックにもなります (たとえば特色の項目を持つ `.ase` パレット)。その特色の項目は、ブックでの名前のまま特色として開きます。一つを適用すると、そのインキが図面に追加されます。TraceDraw はライセンスが必要なカラーブックを同梱していませんが、自分が持っているものは、ほかのパレットと同じように開けます。

## 印刷とエクスポートでの特色 {#output}

- PDF ファイルでは、各インキはその名前を持つ分版カラーになるので、印刷所にインキが伝わります。
- 色分解を印刷すると、各インキはシアン、マゼンタ、イエロー、ブラックの版の後に専用の版を持ちます。[印刷](../printing/print.md) を参照してください。
- 画面上と、ビットマップ、SVG、`.cdr` ファイルでは、特色はその濃度での代替色で表示されます。
