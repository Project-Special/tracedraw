# カスタマイズと自動化

TraceDraw は作業の仕方に合わせて設定できます。プログラムと各ツールの
オプション、インターフェイスの見た目、キーボードショートカット、バー、
ワークスペースです。スクリプトで作業を自動化したり、説明から描く AI サービス
をつないだり、図面に費やした時間を記録したりもできます。

オプションは [[menu.tools > menu.tools.options]] にあります。各項目がそれぞれ
のダイアログボックスを開きます。変更はすぐに表示され、[[dialog.ok]] で確定、
[[dialog.cancel]] ですべて元に戻ります。**?** ボタンは、表示中のオプション
ページについてのこのヘルプのページを開きます。
