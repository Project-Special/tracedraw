# 元に戻す、ズーム、パン

どの変更も元に戻せます。また、図面をどのズームレベルでも、どの位置からでも見られます。ズームとパンで図面が変わることはありません。

## 元に戻す、やり直す {#undo}

- [[menu.edit > menu.edit.undo]] (<kbd>Ctrl+Z</kbd>) は最後の変更を取り消し、[[menu.edit.redo]] (<kbd>Ctrl+Shift+Z</kbd>) はそれをもう一度行います。
- 標準ツールバーの「元に戻す」と「やり直し」の横の矢印は、操作の段階を一覧します。段階を選ぶと、そこまでのすべての変更を元に戻すか、やり直します。
- [[menu.edit.repeat]] は、最後のコマンドをもう一度適用します。たとえば次に選んだオブジェクトに適用できます。

### 元に戻すパネル {#undo-docker}

[[docker.undo]] パネルは、図面のすべての変更を古い順に一覧します。段階をクリックすると、図面をその段階の直後の状態に戻します。後の段階をクリックすると、再び先に進みます。[[menu.window > menu.window.dockers]] から開きます。

![元に戻すパネル](../../img/get-started-undo-and-views-undo-docker.png)

## ズーム {#zoom}

- マウスホイールを回すと、ポインターを中心にズームインまたはズームアウトします。
- 標準ツールバーのズームボックスを使います: レベルを入力するか、一覧から選ぶか (10% から 1600%)、選択範囲、すべてのオブジェクト、ページ、ページの幅、ページの高さに合わせてズームします。
- [[menu.view > menu.view.zoom_in]] と [[menu.view.zoom_out]] は 1 段階ズームします。[[menu.view.zoom_to_fit]] (<kbd>F4</kbd>) はすべてのオブジェクトを、[[menu.view.zoom_to_page]] (<kbd>Shift+F4</kbd>) はページを、[[menu.view.zoom_to_selected]] (<kbd>Shift+F2</kbd>) は選択範囲を表示します。
- トラックパッドのピンチでズームできます。タッチスクリーンでは、どのツールでも 2 本指でパンとピンチができます。

### ズームツール {#zoom-tool}

[[tool.zoom]] ツール (<kbd>Z</kbd> または <kbd>F2</kbd>) を選んでから:

- クリックすると、その位置を中心に 2 倍にズームインします。
- <kbd>Shift</kbd>+クリックまたは右クリックすると、2 分の 1 にズームアウトします。
- 長方形をドラッグすると、その長方形がウィンドウいっぱいになるようにズームします。

ツールのボタンをダブルクリックすると、すべてのオブジェクトに合わせてズームします。

## パン {#pan}

- どのツールでも、マウスの中ボタンを押したままドラッグします。
- [[tool.pan]] ツール (<kbd>H</kbd>) を選んでドラッグします。
- <kbd>Ctrl</kbd>+ホイールで上下に、<kbd>Alt</kbd>+ホイールで左右にスクロールします。
- スクロールバーを使います。スクロールバーはページとその周囲 1 ページ分の範囲をカバーします。
- スクロールバーの間の角にあるナビゲーターボタンを押したまま、ページのサムネイル上でポインターを動かします。
- <kbd>PgUp</kbd> と <kbd>PgDn</kbd> で前のページと次のページに移動します。

ホイールでズームではなくスクロールするには、[[menu.tools > menu.tools.options > menu.tools.options_tools]] の [[options.zoom_pan]] ページでマウスホイールの動作を変更します。すると、ホイールでスクロール、<kbd>Shift</kbd>+ホイールで左右にスクロール、<kbd>Ctrl</kbd>+ホイールでズームになります。[ツールのオプション](../customize/tool-options.md#zoom-pan) を参照してください。

## 表示 {#views}

[[menu.view]] メニューでは、オブジェクトの描き方を選びます: [[menu.view.wireframe]] はアウトラインだけを表示し、[[menu.view.normal]] と [[menu.view.enhanced]] は塗りつぶしと効果を描き、[[menu.view.pixels]] は図面をエクスポートしたときのピクセルとして表示します。[[menu.view.fullscreen_preview]] はページだけを画面に表示します。何かキーを押すと戻ります。[[menu.view.preview_selected_only]] は、そのプレビューを選択範囲に限定します。[[menu.view]] メニューでは、定規、グリッド、ガイドライン、裁ち落とし、印刷可能領域の表示と非表示も切り替えます。[定規、グリッド、ガイドライン](../pages-layout/guidelines-and-grid.md) を参照してください。
