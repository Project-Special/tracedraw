# TraceDraw ヘルプへようこそ

TraceDraw は無料のオープンソースのベクター描画プログラムです。どのサイズでも
鮮明なままの図形、線、テキストで、イラスト、ロゴ、図表、レイアウト、印刷物を
描き、ビットマップと組み合わせることができます。同じプログラムが Windows、
macOS、Linux と Web ブラウザーで動きます。

このヘルプでは、TraceDraw での作業の手順と、各ダイアログボックス、パネル、
ツールの働きを説明します。

## このヘルプの構成 {#organization}

左側の目次は作業の流れに沿っています。

- **はじめに** では、ワークスペース、新しい図面、開くことと保存を紹介します。
- **線、図形、アウトライン**、**オブジェクト、シンボル、レイヤー**、
  **カラー、塗りつぶし、透明度** では、オブジェクトの描画と配置を扱います。
- **特殊効果**、**テキスト**、**テンプレートとスタイル**、
  **ページとレイアウト**、**ビットマップ** では、残りの描画作業を扱います。
- **印刷**、**Web グラフィック**、**ファイル形式** では、作品を TraceDraw
  から書き出す方法を扱います。
- **カスタマイズと自動化** ではオプション、ワークスペース、スクリプト、AI
  機能を扱い、**リファレンス** ではすべてのメニューコマンド、ツール、パネル、
  キーボードショートカットを一覧します。

**検索** タブではページに含まれる任意の語でページを探せます。上部の言語一覧
では同じページを別の言語で読めます。

## TraceDraw の中でヘルプを見る {#in-the-app}

- <kbd>F1</kbd> キーを押すと、目の前にあるもののページが開きます。開いている
  ダイアログボックス、なければ表示中のパネル、それもなければアクティブな
  ツールです。
- ダイアログボックスやオプションページの下にある **?** ボタンをクリックすると、
  そのページが開きます。
- [[menu.help > menu.help.help_topics]] を選ぶと、このページが開きます。
- [[docker.hints]] パネルは作業中のアクティブなツールを説明し、その
  [[hint.learn_more]] リンクはここにあるツールのページを開きます。
  [ヒント](get-started/hints.md) を参照してください。

ページは Web ブラウザーで、TraceDraw に設定された言語で開きます。
