# ビットマップ

ビットマップは、写真やスキャン画像のようにピクセルでできた画像です。
TraceDraw はビットマップを図面に配置し、カラーモードとサイズを変え、傾きを
直し、色をマスクし、効果を適用し、図形にトレースします。ベクターオブジェクト
をビットマップに変換することもできます。

画像を取り込むには [[menu.file > menu.file.import]] を使います。
[ファイルの読み込み](../file-formats/import.md) を参照してください。
ビットマップを選択すると、プロパティバーにビットマップのコマンド (編集、
切り抜き、トレース、傾き補正、リサンプル) が表示されます。効果については
[ビットマップ効果](../effects/bitmap-effects.md) を参照してください。
