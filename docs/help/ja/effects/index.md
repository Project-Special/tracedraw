# 特殊効果

効果は、オブジェクト自体を変えずに見た目を変えます。ブレンドは 2 つの
オブジェクトの間を埋め、輪郭は周りに輪を描き、エンベロープは曲げ、押し出しは
立体に見せ、影はページから浮かせます。ほとんどの効果は **ライブ** です。
オブジェクトは自分の形を保ち、効果はそこから描かれるので、いつでも効果を変更
したり取り除いたりできます。

効果は [[menu.effects]] メニュー、ツールボックスの効果フライアウト、
それぞれのパネルにあります。[ビットマップ効果](bitmap-effects.md) は画像、
または画像として描かれるオブジェクトのピクセルを変えます。
