# Einstellungen zurücksetzen

Wenn Ihre Einrichtung durcheinandergeraten ist, können Sie jede Einstellung auf
den Auslieferungszustand von TraceDraw zurücksetzen. Ihre Zeichnungen bleiben
dabei unberührt.

## Alle Einstellungen zurücksetzen {#reset}

- Wählen Sie [[options.reset_all]] auf der Seite [[options.general]] unter
  [[menu.tools > menu.tools.options > menu.tools.options_global]].
- Oder drücken Sie <kbd>F8</kbd>, während beim Start von TraceDraw der
  Startbildschirm angezeigt wird.

TraceDraw fragt zuerst nach. **Zurücksetzen** stellt jede Einstellung wieder
her, behält aber die Liste der zuletzt verwendeten Zeichnungen, den zuletzt
benutzten Ordner und die Fenstergröße. [[dialog.cancel]] ändert nichts.

![Die Rückfrage vor dem Zurücksetzen der Einstellungen](../../img/customize-reset-settings.png)

Um nur einen Teil zurückzusetzen: Die Werkzeugpalette und die Leisten haben
eigene Befehle zum Zurücksetzen (siehe
[Der Arbeitsbereich](../get-started/workspace.md#arranging)), und die Wahl
eines integrierten Arbeitsbereichs stellt dessen eigene Leisten ein (siehe
[Arbeitsbereiche](workspaces.md)).
