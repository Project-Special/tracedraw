# Anpassen und automatisieren

TraceDraw lässt sich auf Ihre Arbeitsweise einstellen: Optionen für das
Programm und für jedes Werkzeug, das Aussehen der Oberfläche, Tastenkürzel,
Leisten und Arbeitsbereiche. Sie können auch Arbeit mit Skripten
automatisieren, einen KI-Dienst anbinden, der nach einer Beschreibung zeichnet,
und die Zeit erfassen, die Sie mit einer Zeichnung verbringen.

Die Optionen finden Sie unter [[menu.tools > menu.tools.options]]: Jeder
Eintrag öffnet ein eigenes Dialogfeld. Änderungen sind sofort zu sehen;
[[dialog.ok]] behält sie, [[dialog.cancel]] stellt alles wieder her. Die
Schaltfläche **?** öffnet die Seite dieser Hilfe zur angezeigten Optionsseite.
