# Erste Schritte

Diese Seiten stellen TraceDraw vor: die Teile des Fensters, wie Sie Zeichnungen
anlegen, öffnen und speichern, wie Sie sich in einer Zeichnung bewegen und
Arbeitsschritte rückgängig machen, und wo Sie beim Zeichnen Hilfe finden.

TraceDraw läuft unter Windows, macOS und Linux sowie im Webbrowser, ohne dass
etwas installiert werden muss. Beides ist dasselbe Programm; die wenigen
Unterschiede der Browserversion erklärt [Die Browserversion](browser-version.md).
