# Das Andockfenster Hinweise

Das Andockfenster [[docker.hints]] erklärt das Werkzeug, das Sie gerade
verwenden, während Sie es verwenden. Es ist anfangs geöffnet, neben
[[docker.properties]] und [[docker.objects]]; öffnen Sie es erneut mit
[[menu.help > menu.help.hints]] oder über [[menu.window > menu.window.dockers]].

![Das Andockfenster Hinweise](../../img/get-started-hints.png)

## Was das Andockfenster zeigt {#pages}

- Die **Startseite** stellt das Andockfenster vor und listet Themen auf, etwa
  Linien zeichnen, Formen, Objekte auswählen, verschieben und drehen, Effekte,
  Umrisse, Füllungen, Text, KI und Hilfe erhalten. Jedes Thema ist ein Link.
- Eine **Themenseite** erklärt das Thema und listet die passenden Werkzeuge
  auf, jedes mit Symbol, Namen und Funktion. Klicken Sie auf ein Werkzeug, um
  seine Seite zu sehen.
- Eine **Werkzeugseite** erklärt die Verwendung des Werkzeugs, eine Anweisung
  pro Zeile mit den Tasten in Fettschrift, und verweist auf das Thema, das das
  Werkzeug auflistet.

Jede Seite endet mit [[hint.learn_more]], einem Link zu der Seite dieser Hilfe,
die das Werkzeug oder Thema ausführlich erklärt.

## Zwischen Seiten wechseln {#navigation}

Wenn Sie ein anderes Werkzeug wählen, zeigt das Andockfenster die Seite dieses
Werkzeugs. Die Leiste unten im Andockfenster hat links [[hint.home]] und rechts
[[hint.back]] und Vorwärts, wie ein Webbrowser.
