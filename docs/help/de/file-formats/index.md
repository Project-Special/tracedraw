# Dateiformate

TraceDraw speichert in seinem eigenen Format `.tdraw`, das alles bewahrt, und
speichert auch `.cdr`-Dateien. Es öffnet und importiert viele andere Formate
und exportiert Vektor-, Bitmap- und Druckformate. Diese Seiten listen die
Formate auf und erklären Importieren, Exportieren und das Veröffentlichen von
PDF-Dateien.
