# Drucken

TraceDraw druckt, indem es ein druckfertiges PDF der Bögen erstellt, das der
Betrachter Ihres Systems an den Drucker schickt. Diese Seiten erklären das
Dialogfeld Drucken und seine Vorschau, wie Sie Daten in einen Entwurf
einmischen, um viele Fassungen zu drucken, wie Sie eine Zeichnung vor dem Druck
prüfen und wie Sie Banner mit einem Rand und Ösen fertigstellen.
