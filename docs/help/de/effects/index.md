# Spezialeffekte

Effekte ändern das Aussehen eines Objekts, ohne das Objekt selbst zu ändern:
Eine Überblendung füllt den Raum zwischen zwei Objekten, eine Kontur zeichnet
Ringe um eines, eine Hülle verbiegt es, eine Extrusion lässt es massiv wirken,
ein Schatten hebt es von der Seite ab. Die meisten Effekte sind **dynamisch**:
Das Objekt behält seine eigene Form, und der Effekt wird daraus gezeichnet,
sodass Sie ihn jederzeit ändern oder entfernen können.

Die Effekte finden Sie im Menü [[menu.effects]], im Flyout Effekte der
Hilfsmittelpalette und in eigenen Andockfenstern.
[Bitmap-Effekte](bitmap-effects.md) ändern die Pixel von Bildern oder von
Objekten, die als Bilder gezeichnet werden.
