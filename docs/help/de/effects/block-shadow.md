# Blockschatten

Ein Blockschatten ist ein massiver Schatten, der geradlinig von einem Objekt
ausgeht, als wäre das Objekt ein dicker Block. Er wird unter dem Objekt als eine
gefüllte Form gezeichnet, was sich für Schilder und Folienschnitt eignet.

## Einen Blockschatten hinzufügen {#create}

1. Wählen Sie das Werkzeug [[tool.block_shadow]] aus dem Flyout für Effekte.
2. Ziehen Sie von einem Objekt in die Richtung, in die der Schatten gehen soll.

## Einstellungen {#settings}

In der Eigenschaftsleiste:

- **Tiefe**: wie weit der Schatten reicht.
- **Richtung**: sein Winkel, 0 nach rechts, gegen den Uhrzeigersinn.
- **Farbe**: anfangs 60 % Schwarz.
- **Abstand**: ein freier Streifen zwischen Objekt und Schatten (anfangs 0).
- **Blockschatten entfernen** entfernt den Effekt.

Ist ein Objekt mit Schatten ausgewählt, ändern die Felder seinen Schatten;
andernfalls legen sie den nächsten fest.
