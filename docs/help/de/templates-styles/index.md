# Vorlagen und Stile

Vorlagen und Stile sparen Arbeit, die Sie sonst wiederholen würden. Eine
**Vorlage** ist eine fertige Zeichnung als Ausgangspunkt. Ein **Stil** ist ein
benannter Satz aus Füllung, Umriss und Transparenz, der mit den Objekten
verbunden bleibt, die ihn nutzen, sodass eine Änderung sie alle umgestaltet.
Die **Standardeigenschaften** bestimmen, wie neue Objekte aussehen.

Farbstile, die für einzelne Farben genauso funktionieren, erklärt
[Farbstile](../color/color-styles.md).
