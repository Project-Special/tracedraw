# Für das Web exportieren

[[menu.file > menu.file.export_for > menu.file.export_for_web]] öffnet das
Dialogfeld Exportieren, eingerichtet für Bildschirme: PNG mit 96 dpi. Es behält
eigene Einstellungen, getrennt von [[menu.file.export]].
[[menu.file.export_for_office]] tut dasselbe für Office-Dokumente (PNG mit
150 dpi).

![Das Dialogfeld Exportieren](../../img/file-formats-export.png)

## Ein Format wählen {#formats}

- **PNG**: scharfe Kanten und Transparenz; am besten für Logos, Symbole und
  Illustrationen.
- **JPEG**: kleine Dateien für Fotos; keine Transparenz. Stellen Sie die
  **Qualität** ein (1 bis 100).
- **WebP**: kleine Dateien mit Transparenz; stellen Sie die Qualität ein.
- **GIF**: wenige Farben, mit Transparenz.
- **SVG**: Vektorgrafiken, die in jeder Größe scharf bleiben und Links sowie
  Objektnamen behalten.
- **HTML**: eine Webseite mit der Zeichnung.

## Größe und Auflösung {#size}

Stellen Sie bei Bitmap-Formaten die **Auflösung** ein oder geben Sie die
**Breite** oder **Höhe** in Pixeln ein: Die andere Seite folgt den Proportionen
der Seite. Für ein Symbol mit 32 mal 32 Pixeln geben Sie 32 ein. Bei
eingeschaltetem **Transparenter Hintergrund** bleiben die leeren Teile der
Seite in PNG-, WebP- und GIF-Dateien transparent.

**Nur Auswahl** exportiert nur die ausgewählten Objekte, auf sie
zugeschnitten; **Alle Seiten** exportiert jede Seite. Die Vorschau zeigt, was
geschrieben wird, und das Dialogfeld schätzt die Dateigröße.

## Vor dem Exportieren von Text {#text}

[[menu.text > menu.text.make_web_compatible]] vereinfacht Text für das Web.
Um viele Seiten oder Objekte auf einmal zu exportieren, siehe
