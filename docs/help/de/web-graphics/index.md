# Webgrafiken

Grafiken für Webseiten, Apps und Bildschirme sind meist Bitmaps (PNG, JPEG,
WebP, GIF) in Bildschirmauflösung oder SVG-Dateien, die in jeder Größe scharf
bleiben. Diese Seiten erklären, wie Sie sie einzeln exportieren und wie Sie
viele Seiten und Objekte auf einmal exportieren.

Objekte können auch Links tragen, die in exportierten SVG-, HTML- und
PDF-Dateien funktionieren; siehe [Links und Lesezeichen](../objects/links.md).
