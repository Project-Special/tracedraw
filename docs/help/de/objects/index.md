# Objekte, Symbole und Ebenen

Jede Form, Linie, jeder Text und jedes Bild einer Zeichnung ist ein Objekt.
Diese Seiten erklären, wie Sie Objekte auswählen, verschieben, skalieren,
drehen und ausrichten, wie Sie sie anordnen, gruppieren und in Ebenen
organisieren, und wie Sie sie als Symbole wiederverwenden.

Sie behandeln auch Objekte mit einer eigenen Aufgabe: Tabellen, Strichcodes und
QR-Codes, Kommentare und die Daten, die Sie Objekten anhängen.
