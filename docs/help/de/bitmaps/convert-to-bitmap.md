# Objekte in Bitmaps umwandeln

[[menu.bitmaps > menu.bitmaps.convert_to_bitmap]] (auch
[[menu.object > menu.object.convert_to_bitmap]]) wandelt die ausgewählten
Objekte in eine einzige Bitmap um. Damit können Sie komplexe Grafiken
reduzieren oder Objekte für Bitmap-Effekte vorbereiten. Es ist ein einziger
Rückgängig-Schritt.

![Das Dialogfeld In Bitmap umwandeln](../../img/bitmaps-convert-to-bitmap.png)

## Einstellungen {#settings}

- **Auflösung**: Wählen Sie aus der Liste (72 bis 600 dpi) oder geben Sie einen
  Wert ein (36 bis 2400; anfangs 300).
- **Farbmodus**: Schwarzweiß (1 Bit), Graustufen (8 Bit), Palette (8 Bit),
  RGB-Farbe (24 Bit, anfangs) oder CMYK-Farbe (32 Bit).
- **Gerastert**: Bei Schwarzweiß und Palette werden Punkte gemischt, um die
  fehlenden Farbtöne anzudeuten.
- **Schwarz immer überdrucken**: Das Schwarz der Bitmap wird über die darunter
  liegenden Farben gedruckt.
- **Kantenglättung** (anfangs ein): glatte Kanten; aus ergibt harte
  Pixelkanten.
- **Transparenter Hintergrund** (anfangs ein); aus legt die Objekte auf Weiß.

Das Dialogfeld zeigt, wie groß die Bitmap unkomprimiert wird.
