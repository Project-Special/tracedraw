# Farben, Füllungen und Transparenzen

Jedes Objekt kann innen eine Füllung und an seiner Kante einen Umriss haben.
Diese Seiten erklären, wie Sie Farben aus den Paletten und dem Andockfenster
[[docker.color]] wählen, welche Füllungen es gibt (eine einfarbige Füllung,
einen Verlauf, ein Muster, eine Textur oder ein Gitter), wie Sie Objekte
durchsichtig machen und wie Sie Farben mit Farbstilen, Schmuckfarben und
Farbmanagement einheitlich halten.
