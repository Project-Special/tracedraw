# Seiten und Layout

Eine Zeichnung kann viele Seiten haben, jede mit eigener Größe und
Ausrichtung. Diese Seiten erklären, wie Sie Seiten hinzufügen, anordnen und
nummerieren, die Dokumentoptionen einstellen (Seitengröße, Layout,
Hintergrund, Anschnitt, Lineale, Raster und Hilfslinien), Hilfslinien setzen,
Objekte einrasten lassen und die Eigenschaften einer Zeichnung lesen.
