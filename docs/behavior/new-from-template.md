# New From Template

File > New From Template (and the Welcome Screen's New from Template
button) opens a dialog for starting a drawing from a template.

## Layout

- Top: a search field (matches a template's name and category), a list
  of where templates come from (All templates, Built in, My templates)
  and a category list (All categories, Blank, Business cards, Flyers,
  Posters, Stationery, Forms, Banners, Social media, Labels, My
  templates).
- Middle: the templates as thumbnails with their names. A click picks
  one, a double click opens it. With Show template details on, a pane at
  the right shows the picked template large with its category, page size
  and source, or "No Selection".
- Bottom left: a button to open any `.tdt` or `.tdraw` file as a
  template (its tooltip names the folder of the user's templates) and a
  slider for the thumbnail size (40 to 160 points, 64 at first).
- Bottom: Show template details (on at first), Open (greyed until a
  template is picked; Enter presses it) and Cancel (Esc).

## Templates

- Blank pages: A4 portrait and landscape, A3, Letter, business card
  (90 x 50 mm), poster A2, web 1920 x 1080 px and social 1080 x 1080 px
  (96 px per inch).
- Designed: two business cards, a sale flyer and an event flyer (A4), a
  poster (A3), a letterhead (A4), a certificate (A4 landscape), an
  invoice (A4), a birthday banner (300 x 100 mm), a quote post
  (1080 x 1080 px) and a round label (60 mm). They are drawn from
  ordinary shapes and paragraph text in Arial, with placeholder text, so
  every part can be edited.
- My templates: the `.tdt` files in the `templates` folder of the
  settings folder (File > Save as Template writes them). Not on the web.

Opening a template makes a new untitled drawing; the template itself is
never changed. A template file that cannot be read leaves a message in
the status bar.

Thumbnails are drawn once per session (192 px on the longer side) and
scaled to the slider's size.

The Welcome Screen's Templates page shows the built-in templates as
thumbnails (a click opens one) and a More templates button for the
dialog.
